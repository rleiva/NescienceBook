In Chapter \ref{chap:Representations}, we addressed the problem of representing possibly abstract entities by means of finite binary strings, called \emph{representations}, that preserve information about them and make them available for scientific investigation. A representation, however, is not sufficient for scientific understanding. Even when it contains relevant information about an entity, it may remain too large, irregular, or unstructured to support explanation, prediction, or further reasoning. The next challenge is therefore to construct descriptions capable of accounting for the information contained in those representations.

In the theory of nescience, descriptions are treated as computational objects: finite binary strings that encode a Turing machine together with an input string. In scientific applications, the machine may encode the regularities underlying a representation, whereas the input may contain parameters, initial conditions, or residual information. The requirement that descriptions be computationally well-defined is essential. It excludes arbitrary linguistic or symbolic expressions that do not specify an executable procedure capable of producing a finite output. It also allows descriptions to be studied within the mathematical framework of computability and algorithmic information theory, where their lengths, outputs, and transformations can be analyzed precisely. 

We distinguish several classes of descriptions according to their mathematical properties. We begin with \emph{decodable descriptions}, which encode computations that halt and produce finite binary strings. Among these, \emph{exact descriptions} are those that reproduce a specified representation without error. A particularly important subclass consists of \emph{minimal descriptions}, the shortest exact descriptions of a given representation, which provide a theoretical benchmark for descriptive optimality. Unfortunately, exact reconstructions are too restrictive; we therefore require \emph{extended descriptions}, which offer a broader theoretical framework capable of encompassing partial and approximate descriptions. In practice it is generally not possible to establish either exactness or extension; consequently, scientific inquiry proceeds by means of \emph{effective descriptions}, computational descriptions that have been explicitly formulated, investigated, or adopted within a scientific context.

Descriptions are also rarely considered in isolation. Scientific inquiry involves pairing representations with descriptions that attempt to account for them, forming what we call \emph{hypotheses}. Moreover, researchers generally restrict their attention to particular families of descriptions, such as linear models, systems of differential equations, decision trees, or neural networks. These restricted families constitute \emph{model classes}, which organize the space of possible descriptions according to shared computational structures or modeling assumptions.

Finally, scientific descriptions evolve as knowledge develops. Existing descriptions may be enriched with additional information, simplified by removing unnecessary components, combined to account for joint representations, or evaluated relative to previously established background knowledge. This chapter introduces operations such as augmentation, reduction, and conditioning to formalize these transformations. It also extends the descriptive framework from individual representations to collections of representations associated with broader research areas.

\section{Decodable Descriptions}
\label{sec:decodable_descriptions}

The theory of nescience requires descriptions to be computationally well-defined. In particular, a description must encode a Turing machine together with an input on which the computation halts. This requirement excludes arbitrary symbolic expressions that do not specify an effective procedure for producing a finite output.

Throughout this chapter, we assume a fixed, effective, uniquely decodable encoding of Turing machines and their inputs. The permitted machines are drawn from a computably enumerable family of prefix-free Turing machines, sufficiently expressive to simulate arbitrary Turing computations and generate any finite binary string. Here, prefix-freeness means that, for each permitted machine, the set of inputs on which it halts is prefix-free. We also assume that arbitrary Turing computations can be effectively embedded into permitted machines with a single designated input that halts exactly when the simulated computation halts. We further assume that the complete description encoding forms an optimal universal prefix-free description system, so that its induced description complexity satisfies the invariance theorem for prefix-free Kolmogorov complexity. The encoding convention is fixed throughout the theory, so that description lengths can be compared consistently.

\begin{definition}
\label{def:description_model}
Let $d\in\mathcal{B}^\ast$ be a binary string of the form
\[
d=\langle TM,a\rangle,
\]
where $TM$ is the encoding of a permitted prefix-free Turing machine and $a\in\mathcal{B}^\ast$ is an input string. If
\[
TM(a)\downarrow,
\]
then $d$ is called a \emph{decodable description}\index{Decodable description}.
\end{definition}

A decodable description therefore encodes a computation that terminates and produces a finite binary string. The requirement of termination distinguishes decodable descriptions from arbitrary encodings of computational procedures, which may fail to halt on their specified inputs.

We collect all decodable descriptions into a single set.

\begin{definition}
\label{def:set_of_descriptions}
We define the \emph{set of decodable descriptions}\index{Set of decodable descriptions}, denoted by $\mathcal{D}^\top$, as
\[
\mathcal{D}^\top = \left\{d\in\mathcal{B}^\ast:d=\langle TM,a\rangle
\ \wedge\
TM(a)\downarrow\right\}.
\]
\end{definition}

The set $\mathcal{D}^\top$ constitutes the most general descriptive domain considered in the theory of nescience. Every exact, minimal, extended, or effective description must be decodable, since a description that does not terminate cannot produce a representation for further analysis.

The computational requirement has several important consequences. First, every decodable description determines a definite output string, independently of human interpretation. Second, descriptions can be compared through their lengths, computational structures, and the transformations that relate them. Third, their execution can be simulated by a universal Turing machine, providing a common computational framework for scientific modeling.

Nevertheless, decodability must not be confused with decidability. Given an arbitrary candidate description, one can simulate its encoded computation and obtain the output if the computation halts. However, there is no general algorithm that determines whether the computation will eventually terminate. Thus, although decodable descriptions can be executed and their outputs verified when they halt, membership in $\mathcal{D}^\top$ cannot be decided in general.

\subsection*{Description Function}

Since every decodable description produces exactly one finite binary string, it is natural to introduce a function that maps descriptions to their outputs. This function provides the computational connection between descriptions and the strings they generate, independently of whether those strings qualify as representations of entities.

\begin{definition}
\label{def:description_function}
We define the \emph{description function}\index{Description function}, denoted by $\Gamma$, as the function
\[
\Gamma:\mathcal{D}^\top\longrightarrow\mathcal{B}^\ast
\]
that maps each decodable description $d=\langle TM,a\rangle$ to the finite binary string produced by its computation:
\[
\Gamma(d)=TM(a).
\]
\end{definition}

The description function is total on $\mathcal{D}^\top$, since every decodable description encodes a computation that halts. Moreover, it can be evaluated by a fixed universal Turing machine that interprets the encoded machine and simulates its execution on the specified input. The universal simulation is partially computable over arbitrary binary strings, but it always terminates when its input belongs to $\mathcal{D}^\top$. Thus, $\Gamma$ is the restriction of a partial computable universal evaluation procedure to its halting domain.

This distinction is important because the totality of $\Gamma$ on $\mathcal{D}^\top$ does not imply that membership in $\mathcal{D}^\top$ is decidable. The function produces an output for every element of its domain, but there is no general algorithm that determines whether an arbitrary binary string belongs to that domain.

It is also important to distinguish the output of a description from a representation of an entity. The function $\Gamma$ is defined purely computationally and may produce any finite binary string, whether or not that string belongs to the theoretical set of representations $\mathcal{R}$. In particular, decodability imposes no semantic requirement on the output.

The description function also depends on the chosen encoding convention and universal interpreter. For the remainder of the theory, we assume that this convention is fixed, so that $\Gamma$ provides a common reference for all descriptions.

A fundamental property of the description function is that every finite binary string can be produced by at least one decodable description.

\begin{proposition}
\label{prop:description_function_surjective}
The description function is surjective onto $\mathcal{B}^\ast$. That is,
\[
\Gamma(\mathcal{D}^\top)=\mathcal{B}^\ast.
\]
\end{proposition}

\begin{proof}
Let $r\in\mathcal{B}^\ast$ be an arbitrary finite binary string. Construct a permitted prefix-free Turing machine $TM_r$ that, on a designated input $a_0$, outputs $r$ and halts, and that does not halt on any other input. Its halting domain is therefore the singleton $\{a_0\}$, which is prefix-free.

Let $d=\langle TM_r,a_0\rangle$. Then $d\in\mathcal{D}^\top$ and $\Gamma(d) = TM_r(a_0) = r$. Since $r$ was arbitrary, every finite binary string belongs to the image of $\Gamma$. Therefore $\Gamma(\mathcal{D}^\top)=\mathcal{B}^\ast$.
\end{proof}

This proposition establishes that every finite binary string admits at least one decodable description capable of reproducing it exactly. Consequently, the principal difficulty of scientific description is not the mere existence of a computational procedure that generates a representation. Such a procedure always exists for finite representations. The challenge is to find descriptions that capture their regularities in an informative and economical manner.

The computational nature of the description function also imposes important limitations on the decidability of its domain.

\begin{proposition}
\label{prop:decodable_descriptions_enumerable}
The set $\mathcal{D}^\top$ is recursively enumerable but not decidable.
\end{proposition}

\begin{proof}
Since the permitted machine encodings are effectively enumerable, one can enumerate all candidate descriptions $d=\langle TM,a\rangle$ and simulate their computations by dovetailing. Whenever a computation halts, its description can be enumerated. Every element of $\mathcal{D}^\top$ will eventually be produced, so $\mathcal{D}^\top$ is recursively enumerable.

To establish undecidability, suppose that membership in $\mathcal{D}^\top$ were decidable. Given an arbitrary Turing machine $M$ and input $x$, construct effectively a permitted prefix-free machine $TM_{M,x}$ that, on a designated input $a_0$, simulates $M(x)$ and halts if and only if $M(x)$ halts. The machine is undefined on all other inputs, so its halting domain is either empty or the singleton $\{a_0\}$, both of which are prefix-free.

Then
\[
\langle TM_{M,x},a_0\rangle\in\mathcal{D}^\top
\quad\Longleftrightarrow\quad
M(x)\downarrow.
\]

A decision procedure for membership in $\mathcal{D}^\top$ would therefore decide the halting problem, which is impossible. Hence $\mathcal{D}^\top$ is not decidable.
\end{proof}

This result identifies an important limitation of the computational framework. Although the set of decodable descriptions can be enumerated in principle, there is no general procedure that determines whether an arbitrary candidate is decodable. This distinction between recursive enumerability and decidability is fundamental to understanding the computational limitations of scientific description.

Decodable descriptions thus establish the broadest computational domain of the theory. They guarantee that a description can produce a definite finite string, but they impose no requirement concerning what that string represents, how economically it is generated, or whether the computational procedure captures any meaningful regularity.

\section{Exact Descriptions}
\label{sec:exact_descriptions}

The preceding section introduced decodable descriptions as computational objects capable of producing finite binary strings. However, decodability alone does not establish any relationship between a description and a particular representation. A description may generate an arbitrary string without providing information about the representation under investigation. To establish such a relationship, we begin by considering descriptions that reconstruct a specified representation exactly. These descriptions provide a natural theoretical reference for scientific modeling: they generate the intended representation without error, although they may differ substantially in length, computational structure, and explanatory value. Exact reconstruction is a stronger requirement than decodability, but it does not guarantee that a description is economical or that its output adequately represents an entity. These additional questions will be addressed in subsequent sections and chapters.

% Subsection: Exact Descriptions of Representations

\subsection*{Exact Descriptions of Representations}

We say that a description is exact with respect to a given representation when its output coincides with that representation.

\begin{definition}
\label{def:descriptions_for_representation}
Let $r\in\mathcal{B}^\ast$ be a finite binary string. We define the \emph{set of exact descriptions of $r$}\index{Exact descriptions!of a representation}, denoted by $\bar{\mathcal{D}}_r$, as
\[
\bar{\mathcal{D}}_r = \left\{d\in\mathcal{D}^\top : \Gamma(d)=r \right\}.
\]
\end{definition}

\noindent
When $r\in\mathcal{R}$, the elements of $\bar{\mathcal{D}}_r$ are called \emph{exact descriptions}\index{Exact description} of the representation $r$.

The definition is deliberately formulated for arbitrary finite binary strings, rather than only for representations. Exactness is a computational property: it concerns whether the output of a description coincides with a specified target string. Whether that string represents an entity is a separate question determined by the representational framework.

The set $\bar{\mathcal{D}}_r$ contains all decodable descriptions that generate $r$, regardless of the computational procedures they employ or their lengths. Different descriptions may reproduce the same string through substantially different mechanisms, ranging from a direct reproduction of the symbols to a compact procedure that exploits their regularities.

\begin{example}
Consider a representation consisting of a long sequence of zeros. One exact description may contain the complete sequence explicitly, while another may encode a procedure that outputs the required number of zeros. Both descriptions generate the same representation, but their lengths and computational structures may differ considerably.
\end{example}

Thus, exact reconstruction alone does not guarantee that a description is economical or scientifically informative. The set $\bar{\mathcal{D}}_r$ provides the reference domain within which minimal descriptions can subsequently be identified.

By Proposition \ref{prop:description_function_surjective}, every finite binary string admits at least one exact description. Therefore,
\[
\bar{\mathcal{D}}_r\neq\varnothing \qquad \text{for every }r\in\mathcal{B}^\ast.
\]

Since the description function assigns a unique output to every decodable description, the exact-description sets associated with distinct strings are disjoint.

\begin{proposition}
\label{prop:disjoint_descriptions_of_representations}
Let $r_1,r_2\in\mathcal{B}^\ast$ with $r_1\neq r_2$. Then
\[
\bar{\mathcal{D}}_{r_1} \cap \bar{\mathcal{D}}_{r_2} = \varnothing.
\]
\end{proposition}
\begin{proof}
Suppose, for contradiction, that there exists $d \in \bar{\mathcal{D}}_{r_1} \cap \bar{\mathcal{D}}_{r_2}$. By definition of exact description $\Gamma(d)=r_1$ and $\Gamma(d)=r_2$. Since $\Gamma$ is a function on its domain, its output is unique. Hence $r_1=r_2$, contradicting the assumption that they are distinct. Therefore the intersection is empty.
\end{proof}

This proposition establishes that an exact description is associated with exactly one output string. Different descriptions may produce the same representation, but a single decodable description cannot produce two different representations under the fixed description function.

The disjointness property can be strengthened into a partition result.

\begin{proposition}
\label{prop:exact_descriptions_partition}
The family $\left\{\bar{\mathcal{D}}_r:r\in\mathcal{B}^\ast\right\}$ forms a partition of $\mathcal{D}^\top$. In particular,
\[
\mathcal{D}^\top = \bigsqcup_{r\in\mathcal{B}^\ast} \bar{\mathcal{D}}_r.
\]
\end{proposition}
\begin{proof}
Let $d\in\mathcal{D}^\top$. Since $\Gamma$ is defined on every decodable description, there exists a unique string $r=\Gamma(d)\in\mathcal{B}^\ast$. By definition, $d\in\bar{\mathcal{D}}_r$. Hence every decodable description belongs to at least one set in the stated family. By Proposition \ref{prop:disjoint_descriptions_of_representations}, exact-description sets corresponding to distinct strings are disjoint. Therefore every decodable description belongs to exactly one such set, and the family forms a partition of $\mathcal{D}^\top$.
\end{proof}

This result provides a complete classification of decodable descriptions according to their outputs. Every description belongs to one and only one exact-description set, independently of the procedure used to generate that output.

For the purposes of the theory of nescience, we are particularly interested in descriptions whose outputs belong to the theoretical set of extended representations $\mathcal{R}$. This motivates the following global definition.

\begin{definition}
\label{def:set_of_exact_descriptions}
We define the \emph{set of exact descriptions}\index{Set of exact descriptions}, denoted by $\bar{\mathcal{D}}$, as
\[
\bar{\mathcal{D}} = \bigcup_{r\in\mathcal{R}} \bar{\mathcal{D}}_r.
\]
\end{definition}

\noindent
Equivalently,
\[
\bar{\mathcal{D}} = \left\{d\in\mathcal{D}^\top:\Gamma(d)\in\mathcal{R}\right\}.
\]

Thus, $\bar{\mathcal{D}}$ contains precisely those decodable descriptions whose outputs are extended representations of at least one entity in the domain under investigation.

The distinction between $\bar{\mathcal{D}}$ and $\mathcal{D}^\top$ is important. The former is restricted by the representational structure of the domain, whereas the latter includes every decodable description, regardless of whether its output represents an entity. Consequently,
\[
\bar{\mathcal{D}}\subseteq\mathcal{D}^\top,
\]
although the inclusion need not be strict. Since the exact-description sets are pairwise disjoint, we also have
\[
\bar{\mathcal{D}}
=
\bigsqcup_{r\in\mathcal{R}}
\bar{\mathcal{D}}_r.
\]

This establishes the global exact-description space without imposing any requirement of minimality. Exact descriptions may contain unnecessary computational structure, and their outputs may correspond to imperfect representations of the entities under investigation.

% Subsection: Exact Descriptions of Entities

\subsection*{Exact Descriptions of Entities}

Descriptions are defined computationally through the strings they produce. Scientific inquiry, however, is ultimately directed toward entities rather than isolated strings. It is therefore useful to associate descriptions with entities through the representations that they generate. A description may be associated with an entity whenever its output belongs to this set.

\begin{definition}
\label{def:descriptions_for_entity}
Let $e\in\mathcal{E}$ be an entity. We define the \emph{set of exact descriptions of $e$}\index{Exact descriptions!of an entity}, denoted by $\bar{\mathcal{D}}_e$, as
\[
\bar{\mathcal{D}}_e = \left\{d\in\mathcal{D}^\top:\Gamma(d)\in\mathcal{R}_e\right\}.
\]
\end{definition}

\noindent
The set $\bar{\mathcal{D}}_e$ contains all decodable descriptions that exactly generate some extended representation of the entity $e$. Unlike $\bar{\mathcal{D}}_r$, which refers to a fixed binary string, $\bar{\mathcal{D}}_e$ allows the output representation itself to vary.

It is important to distinguish exact reconstruction of a representation from adequate representation of an entity. A description $d\in\bar{\mathcal{D}}_e$ generates its output exactly, but the output may be only an imperfect extended representation of $e$. Therefore, membership in $\bar{\mathcal{D}}_e$ does not guarantee that the description provides a complete or accurate account of the entity. This distinction reflects the separation between the representational and descriptive layers of the theory. Exactness concerns the relation between a description and its output, while the adequacy of that output as a representation is determined independently.

The relationship between entity-specific and representation-specific exact-description sets follows directly from their definitions.

\begin{proposition}
\label{prop:descriptions_entity_union}
For every entity $e\in\mathcal{E}$,
\[
\bar{\mathcal{D}}_e = \bigcup_{r\in\mathcal{R}_e}\bar{\mathcal{D}}_r.
\]
\end{proposition}
\begin{proof}
By definition,
\[
d\in\bar{\mathcal{D}}_e \quad\Longleftrightarrow\quad \Gamma(d)\in\mathcal{R}_e.
\]
This holds if and only if there exists some $r\in\mathcal{R}_e$ such that $\Gamma(d)=r$, which is equivalent to $d\in\bar{\mathcal{D}}_r$. Therefore,
\[
\bar{\mathcal{D}}_e = \bigcup_{r\in\mathcal{R}_e} \bar{\mathcal{D}}_r.
\]
\end{proof}

This proposition establishes that the exact descriptions associated with an entity are obtained by collecting the exact descriptions of its individual extended representations. Thus, the descriptive study of an entity remains mediated by the representations through which information about it is encoded.

The next proposition makes explicit the relationship between representability and exact describability.

\begin{proposition}
\label{prop:descriptions_entity_empty_iff_repr_empty}
For every entity $e\in\mathcal{E}$,
\[
\bar{\mathcal{D}}_e=\varnothing \quad\Longleftrightarrow\quad \mathcal{R}_e=\varnothing.
\]
\end{proposition}
\begin{proof}
Suppose first that $\mathcal{R}_e=\varnothing$. By Proposition \ref{prop:descriptions_entity_union},
\[
\bar{\mathcal{D}}_e = \bigcup_{r\in\varnothing}\bar{\mathcal{D}}_r = \varnothing.
\]
Conversely, suppose that $\mathcal{R}_e\neq\varnothing$. Choose any $r\in\mathcal{R}_e$. By Proposition \ref{prop:description_function_surjective}, there exists a decodable description $d\in\mathcal{D}^\top$ such that $\Gamma(d)=r$. Hence $d\in\bar{\mathcal{D}}_r$, and therefore $d\in\bar{\mathcal{D}}_e$. Consequently, $\bar{\mathcal{D}}_e\neq\varnothing$.
\end{proof}

This result shows that an entity admits exact descriptions of its extended representations precisely when it admits at least one extended representation. The existence of such descriptions therefore imposes no additional restriction beyond the existence of the corresponding representation strings.

This equivalence concerns representability through $\mathcal{R}_e$. Its relationship with the stronger notions of oracle-relative and intrinsic knowability depends on the representation oracles and admissibility conditions introduced in Chapter \ref{chap:Representations}.

Although exact-description sets associated with distinct representations are disjoint, the corresponding sets associated with distinct entities need not be. This follows from the fact that extended representations may contain information about more than one entity.

\begin{proposition}
\label{prop:exact_descriptions_entity_intersection}
Let $e_1,e_2\in\mathcal{E}$ be two entities. Then
\[
\bar{\mathcal{D}}_{e_1} \cap \bar{\mathcal{D}}_{e_2} = 
\bigcup_{r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}} \bar{\mathcal{D}}_r.
\]
Consequently,
\[
\bar{\mathcal{D}}_{e_1} \cap \bar{\mathcal{D}}_{e_2} \neq\varnothing
\quad\Longleftrightarrow\quad
\mathcal{R}_{e_1} \cap \mathcal{R}_{e_2} \neq\varnothing.
\]
\end{proposition}
\begin{proof}
Let $d \in \bar{\mathcal{D}}_{e_1} \cap \bar{\mathcal{D}}_{e_2}$. By definition $\Gamma(d)\in\mathcal{R}_{e_1}$ and $\Gamma(d)\in\mathcal{R}_{e_2}$. Hence, setting $r=\Gamma(d)$, we have $r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}$ and $d\in\bar{\mathcal{D}}_r$. Therefore,
\[
d \in \bigcup_{r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}} \bar{\mathcal{D}}_r.
\]
Conversely, suppose that
\[
d \in \bigcup_{r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}} \bar{\mathcal{D}}_r.
\]
Then there exists some $r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}$ such that $\Gamma(d)=r$. Consequently $d\in\bar{\mathcal{D}}_{e_1}$ and $d\in\bar{\mathcal{D}}_{e_2}$, which establishes the equality.

Finally, since every finite binary string admits at least one exact description, the union on the right-hand side is nonempty precisely when $\mathcal{R}_{e_1} \cap \mathcal{R}_{e_2} \neq \varnothing$. This proves the equivalence.
\end{proof}

This proposition reveals an important structural distinction. At the level of individual representations, exact descriptions are uniquely classified by their outputs. At the level of entities, however, the same description may belong to several entity-specific sets whenever its output contains non-trivial information about several entities.

\begin{example}
A representation encoding observations of a physical system may contain information relevant to both its mechanical and thermal behavior. A description that exactly generates this representation may therefore be associated with distinct entities corresponding to these phenomena.
\end{example}

The association between exact descriptions and entities is consequently not necessarily one-to-one, even though the output of every decodable description is uniquely determined.

\subsection*{Recursive Enumerability of Exact Descriptions}

The sets of exact descriptions also possess useful computability-theoretic properties. Since the description function is partial computable, it is possible to enumerate descriptions that produce a specified output, although it is not generally possible to decide whether an arbitrary description belongs to such a set.

For a fixed binary string $r$, the set $\bar{\mathcal{D}}_r$ is recursively enumerable: one can simulate all candidate descriptions and enumerate those that halt with output $r$.

At the level of entities, the situation depends on the computability properties of the corresponding representation set. The following proposition establishes that exact descriptions and extended representations have the same recursive-enumerability status.

\begin{proposition}
\label{prop:De_recursively_enumerable}
Let $e\in\mathcal{E}$ be an entity. Then
\[
\bar{\mathcal{D}}_e \text{ is recursively enumerable}
\quad\Longleftrightarrow\quad
\mathcal{R}_e \text{ is recursively enumerable}.
\]
\end{proposition}
\begin{proof}
Suppose first that $\mathcal{R}_e$ is recursively enumerable. Enumerate all candidate descriptions $d\in\mathcal{B}^\ast$ and simulate their computations by dovetailing. Independently, enumerate the elements of $\mathcal{R}_e$. Whenever a candidate description halts with an output $r$ that has appeared in the enumeration of $\mathcal{R}_e$, enumerate $d$. Likewise, whenever a new element of $\mathcal{R}_e$ appears, enumerate any previously observed descriptions whose outputs coincide with it. Every description $d\in\bar{\mathcal{D}}_e$ eventually halts with an output belonging to $\mathcal{R}_e$, and that output eventually appears in the representation enumeration. Consequently, every element of $\bar{\mathcal{D}}_e$ is eventually produced, and no description outside this set is enumerated. Therefore $\bar{\mathcal{D}}_e$ is recursively enumerable.

Conversely, suppose that $\bar{\mathcal{D}}_e$ is recursively enumerable. Enumerate its elements $d_1,d_2,d_3,\ldots$ and execute each description to obtain its output. By definition, every enumerated description satisfies $\Gamma(d_i)\in\mathcal{R}_e$. Moreover, every representation $r\in\mathcal{R}_e$ admits at least one exact description, so there exists some $d_i\in\bar{\mathcal{D}}_e$ such that $\Gamma(d_i)=r$. Thus, the outputs of the enumerated descriptions produce an effective enumeration of $\mathcal{R}_e$. Hence $\mathcal{R}_e$ is recursively enumerable.
\end{proof}

This proposition establishes that passing from extended representations to their exact descriptions does not alter recursive enumerability. The two sets are related by the description function, and every finite representation admits at least one exact description. The result does not imply that these sets are recursively enumerable in general. In the theory of nescience, membership in $\mathcal{R}_e$ depends on the admissible representations of the entity and on conditions involving Kolmogorov complexity. These theoretical objects are generally inaccessible and need not be recursively enumerable. Furthermore, recursive enumerability does not imply that membership can be decided, nor that an economical or minimal description can be identified effectively. The proposition establishes only that, whenever the representations of an entity can be enumerated, their exact descriptions can also be enumerated, and conversely.

\section{Minimal Descriptions}
\label{sec:minimal_descriptions}

Inspired by the principle of Occam's razor\index{Occam's razor principle}\footnote{Occam's razor concerns the number of assumptions required by an explanation, not merely the number of symbols used to express it.}, when two descriptions reproduce the same representation exactly, it is natural to prefer the shorter one. A shorter description may capture the regularities of the representation more economically, avoiding redundant computational structure or unnecessary information. Such economy is particularly valuable in scientific modeling, where concise descriptions can facilitate comparison, generalization, and further reasoning.

A representation may admit many exact descriptions, each employing a different computational procedure or a different distribution of information between the Turing machine and its input. Although all these descriptions generate the same representation, their lengths may differ substantially. This motivates the concept of a \emph{minimal description}: an exact description that reconstructs a representation using the shortest possible encoding.

Minimal descriptions provide a theoretical reference for descriptive optimality. Their significance follows from their connection with Kolmogorov complexity, which measures the length of the shortest program capable of producing a given string. In the theory of nescience, minimal descriptions play a central role in defining the ideal limit of descriptive knowledge. Nevertheless, minimality concerns only the relationship between a description and its representation. Even a minimal description cannot guarantee perfect knowledge of an entity when the representation itself is inadequate.


% Subsection: Minimal Descriptions of Representations

\subsection*{Minimal Descriptions of Representations}

We define minimality by requiring that no shorter exact description of the same representation exists. This formulation follows the approach used to define minimal representations in Chapter \ref{chap:Representations}, where minimality is characterized by the absence of a shorter alternative satisfying the same reconstruction requirement.

\begin{definition}
\label{def:descriptions_perfect_model}
Let $r\in\mathcal{R}$ be a representation and let $d\in\bar{\mathcal{D}}_r$ be one of its exact descriptions. We say that $d$ is a \emph{minimal description}\index{Minimal description} of $r$ if there is no other description $d'\in\bar{\mathcal{D}}_r$ such that
\[
\ell(d')<\ell(d).
\]
\end{definition}

Thus, a minimal description is an exact description that cannot be replaced by a shorter exact description of the same representation. The definition is relative to the representation under consideration: it does not compare descriptions of different representations, even when those representations are associated with the same entity.

Since a representation may admit several distinct minimal descriptions, it is useful to consider the complete set of descriptions satisfying this condition.

\begin{definition}
\label{def:set_descriptions_perfect_model}
Let $r\in\mathcal{R}$ be a representation. We define the \emph{set of minimal descriptions}\index{Set of minimal descriptions} of $r$, denoted by $\mathcal{D}_r^\star$, as
\[
\mathcal{D}_r^\star = \left\{d\in\bar{\mathcal{D}}_r \;\middle|\;
\nexists d'\in\bar{\mathcal{D}}_r: \ell(d')<\ell(d) \right\}.
\]
\end{definition}

Thus, $\mathcal{D}_r^\star$ collects all exact descriptions of $r$ for which no shorter exact description exists. We use the following notation to refer to its individual elements.

\begin{notation}
We write $d_r^\star$ to denote an arbitrary element of $\mathcal{D}_r^\star$. This notation does not imply uniqueness.
\end{notation}

The definition immediately establishes the inclusion
\[
\mathcal{D}_r^\star\subseteq\bar{\mathcal{D}}_r.
\]

An important question is whether every representation admits a minimal description. Since every finite binary string has at least one exact description, the existence of minimal descriptions follows from the well-ordering of the natural numbers.

\begin{proposition}
\label{prop:minimal_descriptions_exist}
For every representation $r\in\mathcal{R}$,
\[
\mathcal{D}_r^\star\neq\varnothing.
\]
Moreover, the set $\mathcal{D}_r^\star$ is finite.
\end{proposition}
\begin{proof}
By Proposition \ref{prop:description_function_surjective}, every finite binary string admits at least one exact description. Therefore $\bar{\mathcal{D}}_r\neq\varnothing$. Consider the set of description lengths
\[
L_r = \left\{\ell(d):d\in\bar{\mathcal{D}}_r\right\}.
\]
Since $L_r$ is a nonempty subset of the natural numbers, it has a minimum element, say $m$.

By definition of $L_r$, there exists at least one description $d\in\bar{\mathcal{D}}_r$ such that $\ell(d)=m$. Consequently, there cannot exist any $d'\in\bar{\mathcal{D}}_r$ satisfying $\ell(d')<\ell(d)$. By the definition of minimal descriptions, this implies $d\in\mathcal{D}_r^\star$. Therefore $\mathcal{D}_r^\star$ is nonempty.

Furthermore, every element of $\mathcal{D}_r^\star$ has length $m$, since any two minimal descriptions of the same representation must have equal length. As there are only finitely many binary strings of any fixed length, $\mathcal{D}_r^\star$ is finite.
\end{proof}

This proposition establishes that minimal descriptions always exist and that there are only finitely many of them for any fixed representation. However, the existence of a minimal description does not imply that it can be identified effectively.

Minimal descriptions also need not be unique. Different computational procedures, machine encodings, or arrangements of information between the machine and its input may generate the same representation with the same minimum length. All such descriptions belong to $\mathcal{D}_r^\star$ and are equally minimal.

We can extend this concept from individual representations to the global set of representations considered in the theory.

\begin{definition}
\label{def:set_of_minimal_descriptions}
We define the \emph{set of minimal descriptions}\index{Set of minimal descriptions!global}, denoted by $\mathcal{D}^\star$, as
\[
\mathcal{D}^\star = \left\{d\in\bar{\mathcal{D}} \;\middle|\; \exists r\in\mathcal{R}: d\in\mathcal{D}_r^\star \right\}.
\]
\end{definition}

Thus, $\mathcal{D}^\star$ contains all minimal descriptions of representations belonging to the theoretical representation space $\mathcal{R}$. Since every minimal description is exact, and every exact description is decodable, we obtain
\[
\mathcal{D}^\star \subseteq \bar{\mathcal{D}} \subseteq \mathcal{D}^\top.
\]

This hierarchy distinguishes three levels of descriptive restriction: decodable descriptions generate finite strings, exact descriptions reconstruct representations, and minimal descriptions achieve the shortest possible exact reconstruction of those representations.

% Section: Minimal Descriptions and Kolmogorov Complexity

\subsection*{Minimal Descriptions and Kolmogorov Complexity}

The length of a minimal description is closely related to Kolmogorov complexity. Recall that Kolmogorov complexity measures the length of the shortest program capable of producing a given binary string under a fixed universal description system. To make this relationship precise, we must account for the encoding convention used to represent Turing machines and their inputs. For the complexity results in this section, we assume that the fixed description encoding constitutes an optimal universal prefix-free description system. In particular, the complete description codes are prefix-free, and the system can simulate any prefix-free computational description scheme with a constant description-length overhead. This is stronger than requiring each individual Turing machine to have a prefix-free halting domain.

\begin{notation}
We denote by $K_\Gamma(r)$ the Kolmogorov complexity of $r$ relative to the description function $\Gamma$:
\[
K_\Gamma(r) = \min \left\{ \ell(d): d\in\mathcal{D}^\top,\; \Gamma(d)=r \right\}.
\]
\end{notation}

Since $\bar{\mathcal{D}}_r$ is precisely the set of decodable descriptions that generate $r$, the minimum defining $K_\Gamma(r)$ is attained by the minimal descriptions of $r$.

\begin{proposition}
\label{prop:nescience-kolmogorov}
Let $r\in\mathcal{R}$ be a representation and let $d_r^\star\in\mathcal{D}_r^\star$ be a minimal description of $r$. Then
\[
\ell(d_r^\star)=K_\Gamma(r).
\]
Moreover, if $K$ denotes Kolmogorov complexity relative to another optimal universal prefix-free description system, then
\[
\ell(d_r^\star)=K(r)+O(1),
\]
where the additive constant is independent of $r$.
\end{proposition}
\begin{proof}
By the definition of minimal description, there exists no $d\in\bar{\mathcal{D}}_r$ such that $\ell(d)<\ell(d_r^\star)$. Since $\bar{\mathcal{D}}_r$ is nonempty, it follows that
\[
\ell(d_r^\star) = \min_{d\in\bar{\mathcal{D}}_r}\ell(d).
\]
Since
\[
\bar{\mathcal{D}}_r = \left\{ d\in\mathcal{D}^\top: \Gamma(d)=r \right\},
\]
we have
\[
\ell(d_r^\star) = \min \left\{ \ell(d): d\in\mathcal{D}^\top,\; \Gamma(d)=r \right\} = K_\Gamma(r).
\]
The second statement follows from the invariance theorem for optimal universal prefix-free description systems, which establishes that
\[
K_\Gamma(r)=K(r)+O(1).
\]
\end{proof}

This proposition identifies the length of a minimal description with the Kolmogorov complexity of its output relative to the chosen reference description function. If the function $\Gamma$ is also used to define the Kolmogorov complexity $K$ employed throughout the book, the equality becomes exact:
\[
\ell(d_r^\star)=K(r).
\]

For the remainder of the theory, we assume that a fixed optimal universal prefix-free description system has been chosen as the reference for both descriptions and Kolmogorov complexity. Under this convention, the distinction between $K_\Gamma$ and $K$ may be omitted.

The invariance theorem also establishes that the minimum description length is stable, up to an additive constant, under changes between optimal universal description systems.

\begin{corollary}
\label{cor:minimal_descriptions_invariance}
Let $\Gamma$ and $\dot{\Gamma}$ be two optimal universal prefix-free description functions. For a representation $r$, let $d_r^\star$ and $\dot{d}_r^\star$ be minimal descriptions under $\Gamma$ and $\dot{\Gamma}$, respectively. Then there exists a constant $c$, independent of $r$, such that
\[
\left| \ell(d_r^\star) - \ell(\dot{d}_r^\star) \right|
\leq c.
\]
\end{corollary}
\begin{proof}
By Proposition \ref{prop:nescience-kolmogorov},
\[
\ell(d_r^\star)=K_\Gamma(r), \qquad \ell(\dot{d}_r^\star)=K_{\dot{\Gamma}}(r).
\]

The invariance theorem guarantees that the Kolmogorov complexities induced by two optimal universal prefix-free description systems differ by at most an additive constant independent of $r$. The result follows.
\end{proof}

This result shows that minimal-description length is not fundamentally tied to a particular optimal universal encoding convention. However, the additive constant may affect comparisons between descriptions whose lengths are close. Consequently, invariance up to a constant does not imply that all relative rankings of descriptions or hypotheses are independent of the chosen description function.

In practical applications, the description function is therefore fixed in advance, allowing description lengths to be compared consistently within the same computational framework.

Although minimal descriptions exist for every finite representation, they cannot generally be obtained by an effective procedure. This limitation follows from the noncomputability of Kolmogorov complexity.

\begin{proposition}
\label{prop:minimal_descriptions_uncomputable}
There is no algorithm that, given an arbitrary representation $r\in\mathcal{B}^\ast$, always returns a minimal description of $r$ under an optimal universal prefix-free description function.
\end{proposition}
\begin{proof}
Suppose that such an algorithm existed. Given any binary string $r$, the algorithm would return a minimal description $d_r^\star$. By Proposition \ref{prop:nescience-kolmogorov}, its length would satisfy $\ell(d_r^\star)=K_\Gamma(r)$. Since the length of a finite binary string is computable, the algorithm would provide a procedure for computing $K_\Gamma(r)$ for every $r\in\mathcal{B}^\ast$. This contradicts the noncomputability of Kolmogorov complexity for an optimal universal description system. Therefore no such algorithm exists.
\end{proof}

This proposition distinguishes the mathematical existence of minimal descriptions from our ability to discover them. Although every finite representation admits at least one minimal description, there is no general effective procedure that identifies one.

Scientific inquiry must therefore proceed by comparing and refining available descriptions without knowing whether the theoretical optimum has been reached. This limitation is fundamental to the study of descriptive surplus and mismodel.

% Subsection: Incompressibility of Minimal Descriptions

\subsection*{Incompressibility of Minimal Descriptions}

A particularly important consequence of descriptive minimality concerns the algorithmic complexity of the descriptions themselves. A minimal description cannot contain a substantial amount of algorithmically redundant information. If it could be compressed significantly, the compressed version could be used to reconstruct the original description and then execute it, yielding a shorter description of the same representation. This would contradict minimality. The following theorem makes this relationship precise.

\begin{theorem}
\label{th:perfect_incompressible}
Let $r\in\mathcal{R}$ be a representation and let $d_r^\star\in\mathcal{D}_r^\star$ be a minimal description of $r$. Then
\[
K(d_r^\star) \geq \ell(d_r^\star)-c,
\]
for some constant $c$ independent of $r$.
\end{theorem}
\begin{proof}
Since the description function $\Gamma$ can be evaluated by a fixed universal computational procedure, there exists a constant $c_1$ such that
\[
K(\Gamma(d))\leq K(d)+c_1
\]
for every decodable description $d\in\mathcal{D}^\top$. In particular, since $\Gamma(d_r^\star)=r$,
\[
K(r)\leq K(d_r^\star)+c_1.
\]
By Proposition \ref{prop:nescience-kolmogorov}, there exists a constant $c_2$, independent of $r$, such that
\[
\ell(d_r^\star) \leq K(r)+c_2.
\]
Combining these inequalities gives
\[
\ell(d_r^\star) \leq K(d_r^\star)+c_1+c_2.
\]
Therefore,
\[
K(d_r^\star) \geq \ell(d_r^\star)-c,
\]
where $c=c_1+c_2$ is independent of $r$.
\end{proof}

This theorem establishes that minimal descriptions are algorithmically incompressible up to a fixed additive constant. In particular, a minimal description cannot contain an arbitrarily large amount of information that can be removed through algorithmic compression while preserving its ability to reconstruct the intended representation. The result provides an important connection between descriptive optimality and algorithmic randomness. A minimal description is not necessarily random in the everyday sense of being meaningless or disorganized. Rather, it is incompressible in the technical sense established by algorithmic information theory: there is no substantially shorter program that reproduces the description itself. This connection plays a central role in the theory of nescience. Minimal descriptions provide the descriptive component of perfect knowledge, while their incompressibility characterizes the limit of further lossless compression.

It is equally important to note that the converse of Theorem \ref{th:perfect_incompressible} does not hold in general. A description may be algorithmically incompressible without being a minimal description of its output. Incompressibility concerns the internal algorithmic structure of a string, whereas minimality concerns its length relative to all descriptions that generate a particular target.

\begin{proposition}
\label{prop:incompressibility_not_minimality}
There exist decodable descriptions $d$ and representations $r$ such that $\Gamma(d)=r$ and $K(d)\geq\ell(d)-O(1)$ but $d \notin\mathcal{D}_r^\star$. Moreover, the difference between $\ell(d)$ and the minimum description length of $r$ can be arbitrarily large.
\end{proposition}
\begin{proof}
Fix a representation $r_0\in\mathcal{R}$, and consider a sequence of strings $s_n$ whose Kolmogorov complexities increase without bound. For each $s_n$, let $p_n\in\mathcal{D}_{s_n}^\star$ be a minimal description, using the definition of minimal descriptions for arbitrary finite binary targets. Construct a fixed prefix-free machine $TM_0$ that, given a valid description $p$, executes the computation encoded by $p$, discards its output, and then produces $r_0$. Its halting domain is the prefix-free domain of the reference description function. Consider the descriptions $d_n=\langle TM_0,p_n\rangle$. Since $TM_0$ has a fixed encoding, the descriptions can be constructed with constant additional length:
\[
\ell(d_n)=\ell(p_n)+O(1).
\]
Furthermore, $p_n$ can be recovered computably from $d_n$. Therefore,
\[
K(d_n)\geq K(p_n)-O(1).
\]
By Theorem \ref{th:perfect_incompressible},
\[
K(p_n)\geq\ell(p_n)-O(1).
\]
Consequently,
\[
K(d_n)\geq\ell(d_n)-O(1).
\]
However, every $d_n$ generates the same fixed representation $\Gamma(d_n)=r_0$.

Since the complexity of $s_n$ increases without bound, the lengths of $d_n$ also increase without bound. Meanwhile, the minimum description length of $r_0$ remains fixed. Thus, for sufficiently large $n$,
\[
\ell(d_n) > \min_{d\in\bar{\mathcal{D}}_{r_0}}\ell(d),
\]
and hence
\[
d_n\notin\mathcal{D}_{r_0}^\star.
\]
\end{proof}

This proposition demonstrates that incompressibility and descriptive minimality are fundamentally different properties. An incompressible description may contain substantial information that is unnecessary for reconstructing its output. What matters for minimality is not whether the description itself can be compressed, but whether a shorter description of the same representation exists.

Thus, minimality implies incompressibility, but incompressibility alone does not imply minimality.

% Subsection: Minimal Descriptions of Entities

\subsection*{Minimal Descriptions of Entities}

The concept of minimal description can be extended from individual representations to the entities they represent. Since an entity may admit multiple extended representations, each representation may have its own collection of minimal descriptions. It is important, however, to distinguish minimality relative to a representation from perfection relative to an entity. A minimal description reconstructs its target representation using the smallest possible amount of descriptive information, but the representation itself may still be incomplete, inaccurate, or otherwise unsuitable for the entity under investigation. We therefore define minimal descriptions of entities through their associated representations, without assuming that all such descriptions provide perfect knowledge.


\begin{definition}
\label{def:entities_perfect_model}
Let $e\in\mathcal{E}$ be an entity. We define the \emph{set of minimal descriptions of $e$}\index{Minimal descriptions!of an entity}, denoted by $\mathcal{D}_e^\star$, as
\[
\mathcal{D}_e^\star = \left\{d\in\mathcal{D}^\star \;\middle|\; \exists
r\in\mathcal{R}_e: d\in\mathcal{D}_r^\star \right\}.
\]
\end{definition}

Thus, a description belongs to $\mathcal{D}_e^\star$ whenever it is a minimal description of at least one extended representation of the entity $e$.

This definition does not require the description to be shortest among all descriptions associated with the entity. Instead, minimality is evaluated separately for each representation. Consequently, two minimal descriptions belonging to $\mathcal{D}_e^\star$ may have different lengths because they reconstruct different representations of the same entity.

The following proposition establishes the relationship between the existence of minimal descriptions and the existence of representations.

\begin{proposition}
\label{prop:minimal_descriptions_entity_nonempty}
For every entity $e\in\mathcal{E}$,
\[
\mathcal{D}_e^\star\neq\varnothing \quad\Longleftrightarrow\quad \mathcal{R}_e\neq\varnothing.
\]
\end{proposition}
\begin{proof}
Suppose first that $\mathcal{D}_e^\star\neq\varnothing$. By definition, there exists some $r\in\mathcal{R}_e$ such that $\mathcal{D}_r^\star\neq\varnothing$. Therefore $\mathcal{R}_e\neq\varnothing$.

Conversely, suppose that $\mathcal{R}_e\neq\varnothing$. Choose any $r\in\mathcal{R}_e$. By Proposition \ref{prop:minimal_descriptions_exist}, $\mathcal{D}_r^\star\neq\varnothing$. Since $\mathcal{D}_r^\star\subseteq\mathcal{D}_e^\star$, it follows that $\mathcal{D}_e^\star\neq\varnothing$.
\end{proof}

This proposition shows that every entity admitting an extended representation also admits at least one minimal description of that representation. However, this does not imply that the entity can be represented adequately, nor that perfect knowledge of it is attainable. In the theory of nescience, perfect knowledge requires the simultaneous adequacy of the representation and optimality of its description. In particular, the representation must belong to the set of admissible representations $\bar{\mathcal{R}}_e$, while the description must be minimal relative to that representation. Consequently, the descriptions that may participate in a perfect-knowledge pair belong to
\[
\bigcup_{r\in\bar{\mathcal{R}}_e} \mathcal{D}_r^\star,
\]
rather than necessarily to every component of $\mathcal{D}_e^\star$.

This distinction is fundamental. A minimal description of an inadequate representation may reproduce that representation perfectly while still failing to provide an adequate account of the entity. Perfect descriptive reconstruction is therefore necessary at the descriptive level, but it is not sufficient for perfect scientific knowledge.

\section{Extended Descriptions}
\label{sec:extended_descriptions}

The set of exact descriptions $\bar{\mathcal{D}}_r$ associated with a representation $r$ is too restrictive to capture the full range of descriptions relevant to scientific inquiry. By definition, an exact description must reproduce the intended representation without error. Scientific descriptions, however, frequently capture only part of the information contained in a representation, generating outputs that differ from the target while still accounting for some of its regularities.

This motivates the introduction of \emph{extended descriptions}. An extended description need not reconstruct its target representation exactly, but its output must contain non-trivial algorithmic information about that representation. Extended descriptions therefore provide a theoretical generalization of exact descriptions, allowing us to study partial and imperfect computational accounts without abandoning the requirement that they convey genuine information about their targets.

Unlike effective descriptions, which will be introduced in the following section, extended descriptions are defined by an objective mathematical condition rather than by their use in scientific practice. Their membership is determined by the algorithmic information contained in their outputs, independently of whether they have been discovered, proposed, or investigated by scientists. This distinction will be important when introducing mismodel in Chapter \ref{chap:Mismodel}.

% Subsection: Extended Descriptions of Representations

\subsection*{Extended Descriptions of Representations}

A description may contain useful information about a representation even when its output differs from that representation. We characterize this relationship through conditional Kolmogorov complexity. If knowing $\Gamma(d)$ reduces the amount of information required to reconstruct $r$, then the output of $d$ is informative about $r$.

To distinguish genuine informational contributions from small differences attributable to coding conventions, we fix a positive integer $\tau$, called the \emph{information threshold}. This threshold is independent of the particular representation and description under consideration, and is held fixed throughout the theory.

\begin{definition}
\label{def:extended_descriptions_for_representation}
Let $r\in\mathcal{R}$ be a representation. We define the \emph{set of extended descriptions}\index{Extended description} of $r$, denoted by $\mathcal{D}_r$, as
\[
\mathcal{D}_r = \left\{d\in\mathcal{D}^\top \;\middle|\; \Gamma(d)=r \;\lor\;
K(r\mid\Gamma(d))\leq K(r)-\tau \right\}.
\]
\end{definition}

The definition admits two cases. First, every exact description of $r$ qualifies as an extended description, since it reconstructs the representation completely. Second, a description whose output differs from $r$ also qualifies whenever that output reduces the conditional Kolmogorov complexity of $r$ by at least $\tau$ bits.

The explicit inclusion of exact descriptions ensures that the definition remains applicable to representations of very low complexity. For such representations, even complete knowledge of the target may not yield a reduction of $\tau$ bits, because their unconditional complexity is already small.

For non-exact descriptions, the inequality
\[
K(r\mid\Gamma(d))\leq K(r)-\tau
\]
requires a non-trivial informational contribution. It states that the amount of information needed to reconstruct $r$ after observing $\Gamma(d)$ is at least $\tau$ bits smaller than the amount required without that information.

This condition should not be confused with numerical similarity or predictive accuracy. A description may be extended even when its output differs substantially from the target representation as a string. Extendedness concerns algorithmic information, rather than a particular notion of distance, approximation, or scientific explanation.

The definition immediately establishes that exact descriptions are a particular case of extended descriptions.

\begin{proposition}
\label{prop:exact_descriptions_are_extended}
For every representation $r\in\mathcal{R}$,
\[
\bar{\mathcal{D}}_r\subseteq\mathcal{D}_r.
\]
\end{proposition}
\begin{proof}
Let $d\in\bar{\mathcal{D}}_r$. By the definition of exact description $\Gamma(d)=r$. Therefore $d$ satisfies the first condition in the definition of $\mathcal{D}_r$, and hence $d\in\mathcal{D}_r$. This establishes the inclusion.
\end{proof}

This proposition confirms that extended descriptions generalize exact descriptions without excluding any description capable of reconstructing its target perfectly. In particular, the inclusion holds independently of the Kolmogorov complexity of the representation. The converse does not hold in general. A description may contain substantial information about a representation without reproducing it exactly, as the following example illustrates.

\begin{example}
Let $x\in\mathcal{B}^\ast$ be a nonempty binary string of sufficiently high Kolmogorov complexity, and consider a representation $r=xx$ belonging to $\mathcal{R}$. Let $d\in\mathcal{D}^\top$ be a decodable description such that $\Gamma(d)=x$. Since $x\neq xx$, the description does not reconstruct $r$ exactly. Therefore $d\notin\bar{\mathcal{D}}_r$. However, from $x$ one can reconstruct $r=xx$ by a fixed computable procedure. Consequently,
\[
K(r\mid\Gamma(d)) = K(xx\mid x) = O(1).
\]
Moreover,
\[
K(r)=K(xx)=K(x)+O(1).
\]
Since $x$ has sufficiently high Kolmogorov complexity, we can choose it so that
\[
K(r\mid\Gamma(d))\leq K(r)-\tau.
\]
Thus $d\in\mathcal{D}_r$ but $d\notin\bar{\mathcal{D}}_r$. Therefore $\bar{\mathcal{D}}_r\subsetneq\mathcal{D}_r$ for this representation.
\end{example}

This example demonstrates that an extended description may generate a string different from its intended representation while still containing enough information to reconstruct it with little additional effort. The essential property is not equality between the output and the target, but the informational relationship between them.

It is also worth noting that the output of an extended description need not itself belong to the theoretical representation space $\mathcal{R}$. The description function may produce an arbitrary binary string that contains useful information about the target, even when that output does not independently qualify as a representation of any entity under investigation.

% Subsection: Properties of Extended Descriptions

\subsection*{Properties of Extended Descriptions}

Unlike exact descriptions, the sets of extended descriptions associated with distinct representations need not be disjoint. This follows from the fact that a single binary string may contain information about several different representations. The following proposition establishes that such overlap is possible.

\begin{proposition}
\label{prop:extended_descriptions_not_disjoint}
There exist representational domains containing distinct representations $r_1,r_2\in\mathcal{R}$ such that
\[
\mathcal{D}_{r_1}\cap\mathcal{D}_{r_2}
\neq\varnothing.
\]
\end{proposition}

\begin{proof}
Consider a representational domain containing the distinct representations $r_1=x0$ and $r_2=x1$, where $x\in\mathcal{B}^\ast$ is a binary string of sufficiently high Kolmogorov complexity. By Proposition \ref{prop:description_function_surjective}, there exists a decodable description $d\in\mathcal{D}^\top$ such that $\Gamma(d)=x$. Since the final bits of $r_1$ and $r_2$ are fixed, each representation can be reconstructed from $x$ by a fixed computable procedure. Therefore $K(r_1\mid x)=O(1)$ and $K(r_2\mid x)=O(1)$. Furthermore $K(r_1)=K(x)+O(1)$ and $K(r_2)=K(x)+O(1)$. For sufficiently complex $x$, both inequalities
\[
K(r_1\mid\Gamma(d))\leq K(r_1)-\tau
\]
and
\[
K(r_2\mid\Gamma(d))\leq K(r_2)-\tau
\]
hold. Consequently $d\in\mathcal{D}_{r_1}$ and $d\in\mathcal{D}_{r_2}$. Thus $\mathcal{D}_{r_1}\cap\mathcal{D}_{r_2} \neq \varnothing$.
\end{proof}

This proposition shows that extended descriptions do not partition representations in the same way as exact descriptions. An exact description is associated with a unique output string, whereas an extended description may be informative about several distinct representations. This overlap is particularly relevant in scientific practice, where a common mathematical structure or computational model may help account for different datasets or phenomena.

\begin{example}
Consider two representations $r_1$ and $r_2$ consisting of climate observations collected from two nearby cities. The datasets may differ in their measured temperatures, rainfall, and local variations, while sharing a common large-scale seasonal pattern. Let $d$ be a decodable description whose output $\Gamma(d)$ encodes this common seasonal structure. If the seasonal pattern reduces the conditional Kolmogorov complexity of each dataset by at least $\tau$ bits, then $d\in\mathcal{D}_{r_1} \cap \mathcal{D}_{r_2}$. Thus, the same description may contain useful information about multiple representations, even though it does not reproduce either one exactly.
\end{example}

Extendedness depends on the information contained in the output of a description, rather than on the particular computational procedure that produces that output. Consequently, descriptions with identical outputs must have the same extendedness status relative to any fixed representation.

\begin{proposition}
\label{prop:extended_description_depends_only_on_output}
Let $r\in\mathcal{R}$, and let $d_1,d_2\in\mathcal{D}^\top$ satisfy $\Gamma(d_1)=\Gamma(d_2)$. Then
\[
d_1\in\mathcal{D}_r
\quad\Longleftrightarrow\quad
d_2\in\mathcal{D}_r.
\]
\end{proposition}
\begin{proof}
Since $\Gamma(d_1)=\Gamma(d_2)$, the two descriptions satisfy the same exactness condition:
\[
\Gamma(d_1)=r
\quad\Longleftrightarrow\quad
\Gamma(d_2)=r.
\]
Moreover,
\[
K(r\mid\Gamma(d_1))
=
K(r\mid\Gamma(d_2)).
\]
Therefore, they also satisfy the same information-gain condition. By the definition of extended descriptions,
\[
d_1\in\mathcal{D}_r
\quad\Longleftrightarrow\quad
d_2\in\mathcal{D}_r.
\]
\end{proof}

This proposition establishes that extendedness is determined entirely by the output of a description. Two descriptions generating the same string are equally informative about a given representation, regardless of their lengths or computational structures. In particular, extendedness does not measure descriptive economy. One description may be substantially longer than another while both belong to the same extended-description sets. Such differences will become relevant when studying descriptive surplus and mismodel.

A related question concerns the preservation of information when one description is replaced by another. Intuitively, if the output of a new description allows us to reconstruct the output of an informative description, then much of the original informational contribution should be preserved. However, the reconstruction may require additional information. The following proposition establishes a quantitative bound on this possible loss.

\begin{proposition}
\label{prop:extended_description_monotonicity}
There exists a constant $c_0$, depending only on the fixed reference description system, such that for every representation $r\in\mathcal{R}$ and all $d_1,d_2\in\mathcal{D}^\top$,
\[
K(r\mid\Gamma(d_2)) \leq K(r\mid\Gamma(d_1))
+ K(\Gamma(d_1)\mid\Gamma(d_2)) + c_0.
\]
Consequently, if
\[
K(r\mid\Gamma(d_1)) + K(\Gamma(d_1)\mid\Gamma(d_2)) + c_0
\leq K(r)-\tau,
\]
then
\[
d_2\in\mathcal{D}_r.
\]
\end{proposition}
\begin{proof}
Given $\Gamma(d_2)$, one can execute a shortest conditional program that reconstructs $\Gamma(d_1)$ from $\Gamma(d_2)$. Once $\Gamma(d_1)$ has been obtained, a shortest conditional program for reconstructing $r$ from $\Gamma(d_1)$ can be executed. The two computations can be combined using a fixed universal procedure. Therefore, there exists a constant $c_0$, independent of $r$, $d_1$, and $d_2$, such that
\[
K(r\mid\Gamma(d_2)) \leq K(\Gamma(d_1)\mid\Gamma(d_2)) +
K(r\mid\Gamma(d_1)) + c_0.
\]
This establishes the first inequality.

Now suppose that
\[
K(r\mid\Gamma(d_1)) + K(\Gamma(d_1)\mid\Gamma(d_2)) + c_0
\leq K(r)-\tau.
\]
Combining this assumption with the first inequality gives
\[
K(r\mid\Gamma(d_2)) \leq K(r)-\tau.
\]
Hence $d_2$ satisfies the information-gain condition in the definition of extended descriptions, and therefore $d_2\in\mathcal{D}_r$.
\end{proof}

This proposition formalizes the preservation of informational content under computable transformations of description outputs. The amount of information that may be lost is bounded by the conditional complexity of reconstructing the original output from the new one, together with a fixed computational overhead. In particular, when $\Gamma(d_1)$ can be reconstructed from $\Gamma(d_2)$ using a constant-size program, the informational contribution of $d_1$ is preserved up to an additive constant. However, preservation of membership in $\mathcal{D}_r$ additionally requires that the original informational gain be sufficient to absorb this overhead and still satisfy the threshold $\tau$. Thus, a more informative output need not preserve the extendedness classification automatically when the original description lies close to the informational threshold. Nevertheless, the proposition provides a precise quantitative relationship between the descriptive information available before and after the transformation.

% Subsection: Extended Descriptions of Entities

\subsection*{Extended Descriptions of Entities}

The notion of extended description can be generalized from individual representations to the entities they represent. Since an entity may admit multiple extended representations, an extended description of the entity should be informative about at least one of those representations.

This generalization preserves the distinction between the representational and descriptive layers of the theory. A description is associated with an entity through the information its output contains about the representations of that entity, rather than through a direct computational reconstruction of the entity itself.

\begin{definition}
\label{def:extended_descriptions_for_entity}
Let $e\in\mathcal{E}$ be an entity. We define the \emph{set of extended descriptions of $e$}\index{Extended descriptions!of an entity}, denoted by $\mathcal{D}_e$, as
\[
\mathcal{D}_e = \left\{d\in\mathcal{D}^\top\;\middle|\;\exists r\in\mathcal{R}_e: d\in\mathcal{D}_r \right\}.
\]
\end{definition}

Thus, a description belongs to $\mathcal{D}_e$ whenever it is an extended description of at least one representation of the entity $e$. In particular, membership in $\mathcal{D}_e$ does not require the description to reconstruct any representation of $e$ exactly. It is sufficient that its output provide the required informational contribution to at least one such representation.

Since the sets of extended representations associated with distinct entities may overlap, the corresponding sets of extended descriptions may also overlap. A single description can therefore be associated with more than one entity whenever its output contains sufficient information about their representations.

The following proposition makes explicit the relationship between entity-level and representation-level extended descriptions.

\begin{proposition}
\label{prop:extended_descriptions_entity_union}
For every entity $e\in\mathcal{E}$,
\[
\mathcal{D}_e = \bigcup_{r\in\mathcal{R}_e} \mathcal{D}_r.
\]
\end{proposition}
\begin{proof}
By definition,
\[
d\in\mathcal{D}_e \quad\Longleftrightarrow\quad \exists r\in\mathcal{R}_e: d\in\mathcal{D}_r.
\]
This condition is equivalent to
\[
d\in \bigcup_{r\in\mathcal{R}_e} \mathcal{D}_r.
\]
Therefore,
\[
\mathcal{D}_e = \bigcup_{r\in\mathcal{R}_e} \mathcal{D}_r.
\]
\end{proof}

This proposition confirms that extended descriptions of an entity are obtained by collecting the extended descriptions of its individual representations. Consequently, the descriptive analysis of an entity remains mediated by its representational structure, even when descriptions are permitted to contain only partial information about their intended targets.

An immediate consequence concerns the existence of extended descriptions for an entity.

\begin{proposition}
\label{prop:extended_descriptions_entity_empty_iff_repr_empty}
For every entity $e\in\mathcal{E}$,
\[
\mathcal{D}_e=\varnothing \quad\Longleftrightarrow\quad \mathcal{R}_e=\varnothing.
\]
\end{proposition}
\begin{proof}
Suppose first that $\mathcal{R}_e=\varnothing$. By Proposition \ref{prop:extended_descriptions_entity_union},
\[
\mathcal{D}_e = \bigcup_{r\in\varnothing}\mathcal{D}_r = \varnothing.
\]
Conversely, suppose that $\mathcal{R}_e\neq\varnothing$. Choose any $r\in\mathcal{R}_e$. By Proposition \ref{prop:description_function_surjective}, there exists an exact description $d\in\bar{\mathcal{D}}_r$. By Proposition \ref{prop:exact_descriptions_are_extended} $d\in\mathcal{D}_r$. Since $r\in\mathcal{R}_e$, the definition of $\mathcal{D}_e$ gives $d\in\mathcal{D}_e$. Therefore $\mathcal{D}_e\neq\varnothing$.
\end{proof}

This proposition establishes that an entity admits extended descriptions precisely when it admits extended representations. In particular, an entity without any extended representation cannot have an extended description within the theory. Conversely, whenever an entity admits an extended representation, at least one extended description exists, because every finite representation can be generated exactly by a decodable description. This correspondence concerns the existence of descriptions in principle. It does not imply that any such description has actually been discovered or adopted in scientific practice.

% Subsection: Set of Extended Descriptions

\subsection*{Set of Extended Descriptions}

Having defined extended descriptions for individual representations and entities, we can now introduce the corresponding global descriptive space. The global set of extended descriptions contains every decodable description whose output is informative about at least one of these representations, including exact descriptions.

\begin{definition}
\label{def:set_of_extended_descriptions}
We define the \emph{set of extended descriptions}\index{Set of extended descriptions!global}, denoted by $\mathcal{D}$, as
\[
\mathcal{D} = \left\{d\in\mathcal{D}^\top \;\middle|\; \exists r\in\mathcal{R}: d\in\mathcal{D}_r \right\}.
\]
\end{definition}

Equivalently,
\[
\mathcal{D} = \bigcup_{r\in\mathcal{R}} \mathcal{D}_r.
\]
Thus, $\mathcal{D}$ contains all descriptions that reconstruct some theoretical representation exactly or whose outputs contain a sufficient amount of information about at least one such representation. By definition $\mathcal{D}\subseteq\mathcal{D}^\top$. Moreover, since every exact description of a representation is also extended, we have $\bar{\mathcal{D}}\subseteq\mathcal{D}$. Together with the inclusion of minimal descriptions within exact descriptions, established in Section \ref{sec:minimal_descriptions}, this yields the fundamental hierarchy
\[
\mathcal{D}^\star \subseteq \bar{\mathcal{D}} \subseteq \mathcal{D} \subseteq \mathcal{D}^\top.
\]

The hierarchy distinguishes four levels of descriptive restriction. Decodable descriptions establish computational validity; extended descriptions require an informational relationship with a representation; exact descriptions require complete reconstruction; and minimal descriptions require the shortest possible exact reconstruction.

It is important to emphasize that extendedness remains a property of the relationship between a description's output and its intended representation. It does not measure the internal complexity of the description, nor does it establish that the description is accurate, economical, or scientifically useful in any broader sense.

The sets of extended descriptions are also generally inaccessible in practice. Their definitions depend on conditional Kolmogorov complexity, which is not computable in general. Consequently, there is no general effective procedure for verifying the required informational relationship for arbitrary candidate descriptions.

Scientific inquiry therefore cannot proceed by directly enumerating or selecting descriptions from the theoretical set $\mathcal{D}$. Instead, it relies on descriptions that have actually been proposed, constructed, or investigated as models of particular representations.

These descriptions may satisfy the extendedness condition, but they may also be uninformative or entirely incorrect. This motivates the introduction of \emph{effective descriptions}, which distinguish the descriptions available within scientific practice from those that satisfy the theoretical informational requirements established in this section.

% Section: Effective Descriptions

\section{Effective Descriptions}
\label{sec:effective_descriptions}

The set of extended descriptions $\mathcal{D}_r$ contains all decodable descriptions whose outputs carry non-trivial algorithmic information about a representation $r$, including those that reconstruct it exactly. However, this set is generally inaccessible in practice, since membership depends on Kolmogorov complexity, which is not computable in general. Consequently, scientists cannot normally determine whether a proposed description belongs to $\mathcal{D}_r$. Scientific inquiry proceeds instead with descriptions that have been formulated, investigated, or adopted as models of particular representations. Such descriptions may capture substantial regularities, provide only limited information, or even fail to convey any meaningful information about their intended representations. We call these \emph{effective descriptions}.

As in the case of effective representations, the distinction is between theoretical informational relevance and scientific practice. Extended descriptions are defined by a mathematical condition concerning the information contained in their outputs, whereas effective descriptions are determined by their use within a particular scientific context. Their inclusion does not imply correctness, explanatory power, or minimality. Nevertheless, effective descriptions must be decodable, since the theory requires descriptions to encode terminating computational procedures.

% Subsection: Effective Descriptions of Representations

\subsection*{Effective Descriptions of Representations}

Effective descriptions are associated with particular representations through scientific practice. A description may be proposed to explain a representation even when its output fails to contain relevant information about it. Furthermore, the same description may be associated with several representations, reflecting the possibility that a scientific model is applied to different datasets, observations, or phenomena.

As in the case of effective representations, we distinguish between descriptions that satisfy the theoretical informational requirements and those that have actually been considered within scientific practice. The latter are identified through their historical association with particular representations, independently of their descriptive adequacy.

\begin{definition}
\label{def:effective_descriptions}
Let $T$ be a linearly ordered set of time indices, let $r\in\mathcal{B}^\ast$ be a binary string, and let $t\in T$. We define the \emph{set of effective descriptions}\index{Effective description} of $r$ at time $t$, denoted by $\hat{\mathcal{D}}_r^t$, as
\[
\hat{\mathcal{D}}_r^t = \left\{ d\in\mathcal{D}^\top \;\middle|\; d\text{ has been considered as a description of }r \text{ by time }t \right\}.
\]
\end{definition}

The set $\hat{\mathcal{D}}_r^t$ contains all decodable descriptions that have been considered as models of $r$ by time $t$. If no description has been associated with $r$, then $\hat{\mathcal{D}}_r^t$ is empty. Membership does not imply that a description reconstructs its intended representation exactly, or even that its output contains non-trivial information about it.

The definition applies to arbitrary binary strings, rather than only to elements of the theoretical representation space $\mathcal{R}$. This is important because scientific practice may assign descriptions to candidate representations that do not genuinely contain information about any entity under investigation. By definition $\hat{\mathcal{D}}_r^t\subseteq\mathcal{D}^\top$. However, for $r\in\mathcal{R}$, there is no general inclusion relationship between $\hat{\mathcal{D}}_r^t$ and the theoretical set of extended descriptions $\mathcal{D}_r$. An effective description need not be extended, since its output may fail to contain the information required by the definition of extended descriptions. Conversely, an extended description need not have been formulated or considered within scientific practice.

The descriptions that are both effective and extended belong to $\hat{\mathcal{D}}_r^t\cap\mathcal{D}_r$. This intersection identifies those descriptions that have entered scientific consideration and also satisfy the theoretical informational condition associated with the representation. In general, however, membership in this intersection cannot be determined effectively.

As in the case of effective representations, the sets of effective descriptions associated with distinct representations need not be disjoint. A single scientific model may be proposed to account for several representations, even when it is not equally informative about all of them. For example, a mathematical model describing seasonal temperature variation may be applied to observational datasets from several different locations. The same computational description may therefore belong to the effective-description sets of several representations, independently of whether it provides an adequate account of each dataset.

Effective descriptions are defined cumulatively. Once a description has been considered as a model of a representation, it remains part of the historical record, even if it is subsequently rejected or superseded. Consequently, for every fixed $r\in\mathcal{B}^\ast$, $\hat{\mathcal{D}}_r^{t_1} \subseteq \hat{\mathcal{D}}_r^{t_2}$ for all $t_1<t_2$. This monotonicity reflects the cumulative development of scientific modeling rather than an improvement in descriptive quality. As new descriptions are proposed, the historical collection of effective descriptions expands, although some of its members may be inaccurate, redundant, or uninformative.

\begin{notation}
When the time index is clear from the context or refers to the current time, we may omit it and write $\hat{\mathcal{D}}_r$ instead of $\hat{\mathcal{D}}_r^t$.
\end{notation}

% Subsection: Effective Descriptions of Entities

\subsection*{Effective Descriptions of Entities}

Scientific inquiry is usually directed toward understanding entities rather than individual representations. Since an entity may have several effective representations, each associated with different descriptions, it is useful to collect the effective descriptions that have been considered in connection with that entity. These associations are established within scientific practice and need not correspond to the theoretical representations of $e$.

\begin{definition}
\label{def:effective_descriptions_entity}
Let $e\in\mathcal{E}$ be an entity and let $t\in T$. We define the \emph{set of effective descriptions of $e$}\index{Effective descriptions!of an entity}, denoted by $\hat{\mathcal{D}}_e^t$, as
\[
\hat{\mathcal{D}}_e^t = \left\{ d\in\mathcal{D}^\top \;\middle|\; 
\exists r\in\hat{\mathcal{R}}_e^t: d\in\hat{\mathcal{D}}_r^t \right\}.
\]
\end{definition}

Thus, a description belongs to $\hat{\mathcal{D}}_e^t$ whenever it has been considered as a description of at least one effective representation of the entity $e$.

The definition makes explicit that effective descriptions of entities are mediated by effective representations. A description is associated with an entity not because it necessarily captures the entity correctly, but because scientific practice has associated it with a representation assigned to that entity. The corresponding union characterization follows immediately from the definition:
\[
\hat{\mathcal{D}}_e^t = \bigcup_{r\in\hat{\mathcal{R}}_e^t} \hat{\mathcal{D}}_r^t.
\]
Different effective descriptions of the same entity may therefore be associated with different representations, or with alternative models of a common representation. Moreover, the same effective description may belong to the sets associated with several entities, since effective representations themselves need not be uniquely associated with a single entity.

An important consequence concerns the relationship between effective descriptions and effectively known entities.

\begin{proposition}
\label{prop:effective_descriptions_imply_known_entity}
Let $e\in\mathcal{E}$ be an entity and let $t\in T$. If $\hat{\mathcal{D}}_e^t\neq\varnothing$, then $\hat{\mathcal{R}}_e^t\neq\varnothing$.
\end{proposition}
\begin{proof}
Suppose that $\hat{\mathcal{D}}_e^t\neq\varnothing$. Then there exists a description $d\in\hat{\mathcal{D}}_e^t$. By definition, there exists some $r\in\hat{\mathcal{R}}_e^t$ such that $d\in\hat{\mathcal{D}}_r^t$. Therefore $\hat{\mathcal{R}}_e^t\neq\varnothing$.
\end{proof}

This proposition establishes that an entity cannot have an effective description without having at least one effective representation. The converse, however, does not necessarily hold. An entity may have entered scientific consideration through observations or other representations before any computational description has been proposed for it. Thus, the existence of effective representations is a necessary, but not sufficient, condition for the existence of effective descriptions. This distinction separates the recognition of an entity from the development of computational models intended to account for it.

% Subsection: Set of Effective Descriptions

\subsection*{Set of Effective Descriptions}

Having defined effective descriptions for individual representations and entities, we can now introduce the corresponding global descriptive space.

\begin{definition}
\label{def:set_of_effective_descriptions}
Let $t\in T$ be a time index. We define the \emph{set of effective descriptions}\index{Set of effective descriptions}, denoted by $\hat{\mathcal{D}}^t$, as
\[
\hat{\mathcal{D}}^t = \left\{d\in\mathcal{D}^\top \;\middle|\; \exists r\in\hat{\mathcal{R}}^t: d\in\hat{\mathcal{D}}_r^t \right\}.
\]
\end{definition}

Equivalently,
\[
\hat{\mathcal{D}}^t = \bigcup_{r\in\hat{\mathcal{R}}^t} \hat{\mathcal{D}}_r^t.
\]
The set $\hat{\mathcal{D}}^t$ contains all decodable descriptions that have been considered as models of effective representations within the domain of investigation by time $t$.

It is important to emphasize that $\hat{\mathcal{D}}^t$ is determined by scientific practice, rather than by the theoretical informational requirements defining extended descriptions. Consequently, $\hat{\mathcal{D}}^t\subseteq\mathcal{D}^\top$, but there is no general inclusion relationship between $\hat{\mathcal{D}}^t$ and $\mathcal{D}$.

Some effective descriptions may belong to the theoretical set of extended descriptions, while others may fail to contain meaningful information about any representation in the domain. Conversely, extended descriptions may exist mathematically without ever having been considered by scientists. The distinction between these sets reflects the separation between informational relevance and historical scientific activity. The theoretical set $\mathcal{D}$ characterizes descriptions that are informative about representations, whereas $\hat{\mathcal{D}}^t$ records the descriptions that have actually entered scientific consideration.

\begin{notation}
When the time index is clear from the context, we may write $\hat{\mathcal{D}}$ instead of $\hat{\mathcal{D}}^t$.
\end{notation}

% Subsection: Evolution of Effective Descriptions 

\subsection*{Evolution of Effective Descriptions}

Scientific descriptions evolve as new models are proposed, existing models are refined, and previous descriptions are rejected or replaced. A description may initially be considered a plausible explanation of a representation, only to be superseded when additional evidence or a more economical computational account becomes available.

As in the case of effective representations, we distinguish the cumulative historical record of scientific modeling from the collection of descriptions that remain accepted or actively investigated at a particular time.

\begin{proposition}
\label{prop:effective_descriptions_monotonic}
Let $t_1,t_2\in T$ with $t_1<t_2$. Then the following inclusions hold:
\[
\hat{\mathcal{D}}_r^{t_1} \subseteq \hat{\mathcal{D}}_r^{t_2}
\qquad \text{for every }r\in\mathcal{B}^\ast,
\]
\[
\hat{\mathcal{D}}_e^{t_1} \subseteq \hat{\mathcal{D}}_e^{t_2}
\qquad \text{for every }e\in\mathcal{E},
\]
and
\[
\hat{\mathcal{D}}^{t_1} \subseteq \hat{\mathcal{D}}^{t_2}.
\]
\end{proposition}
\begin{proof}
Let $r\in\mathcal{B}^\ast$ and suppose that $d\in\hat{\mathcal{D}}_r^{t_1}$. By definition, $(r,d)\in P_{t_1}$. Since the association sets are cumulative, $P_{t_1}\subseteq P_{t_2}$. Therefore $(r,d)\in P_{t_2}$, and hence $d\in\hat{\mathcal{D}}_r^{t_2}$. This proves the first inclusion.

For the second inclusion, let $d\in\hat{\mathcal{D}}_e^{t_1}$. Then there exists some $r\in\hat{\mathcal{R}}_e^{t_1}$ such that $d\in\hat{\mathcal{D}}_r^{t_1}$. By the monotonicity of effective representations established in Chapter \ref{chap:Representations} $\hat{\mathcal{R}}_e^{t_1} \subseteq \hat{\mathcal{R}}_e^{t_2}$. Combining this with the first inclusion gives $r\in\hat{\mathcal{R}}_e^{t_2}$ and $d\in\hat{\mathcal{D}}_r^{t_2}$. Therefore $d\in\hat{\mathcal{D}}_e^{t_2}$.

Finally, the global inclusion follows from the definition of $\hat{\mathcal{D}}^t$, the monotonicity of the global effective-representation sets, and the first inclusion.
\end{proof}

This proposition formalizes the cumulative development of scientific modeling. Once a description has been considered as a model of a representation, it remains part of the historical record, even if it is later rejected or superseded. Consequently, the collection of effective descriptions associated with a fixed representation, a fixed entity, or the entire domain cannot decrease over time.

However, the monotonic expansion of effective descriptions does not imply that scientific understanding necessarily improves. Newly proposed descriptions may be more informative or economical than their predecessors, but they may also be redundant, misleading, or entirely incorrect. The growth of $\hat{\mathcal{D}}^t$ therefore measures the expansion of descriptive exploration rather than a reduction in mismodel.

The situation differs when considering only descriptions that remain accepted or actively investigated. Such a collection need not be monotonic, since descriptions may be abandoned, replaced, or reinterpreted. Thus, the historical collection of effective descriptions should not be confused with the descriptions currently regarded as the best available accounts of particular representations.

Effective descriptions provide the practical descriptive counterpart of effective representations. Together, they establish the computational material available to scientific inquiry at a given stage of its development. Their associations will allow us to formalize the hypotheses that have entered scientific consideration, while the subsequent measures of miscoding and mismodel will provide the theoretical framework needed to evaluate their quality.

\section{Hypotheses}
\label{sec:hypotheses}

Scientific inquiry involves not only constructing representations of entities and descriptions of those representations, but also considering them together. A representation specifies the information being studied, while its associated description provides a computational account of that information. We refer to such a pair as a \emph{hypothesis}.

In the theory of nescience, a hypothesis is understood as a representation together with a description intended to account for it. This definition is broader than the conventional scientific use of the term, which often refers to a particular testable proposition. Here, the concept provides a common mathematical object for studying the relationship between representations and descriptions, and for evaluating their combined contribution to scientific knowledge.

We distinguish between theoretical hypotheses and those actually considered within scientific practice. The former are defined through extended representations and descriptions, which satisfy the informational requirements established in the preceding sections. The latter are formed from effective representations and descriptions, which may fail to satisfy those requirements. This distinction allows us to characterize both the space of theoretically informative hypotheses and the historical development of scientific inquiry.

% Subsection: Hypotheses of Representations and Entities

\subsection*{Hypotheses of Representations and Entities}

An extended description either reconstructs its intended representation exactly or produces a string that satisfies the informational threshold introduced in Section \ref{sec:extended_descriptions}. Not every representation--description pair satisfies these conditions. We therefore define theoretical hypotheses by requiring that the description be an extended description of the representation with which it is paired.

\begin{definition}
\label{def:hypothesis}
We define the \emph{set of hypotheses}\index{Hypothesis}, denoted by $\mathcal{H}$, as
\[
\mathcal{H}=\{(r,d)\in\mathcal{R}\times\mathcal{D}:d\in\mathcal{D}_{r}\}.
\]
Each element $(r,d)\in\mathcal{H}$ is called a \emph{hypothesis}.
\end{definition}

Thus, a hypothesis consists of an extended representation together with one of its extended descriptions. The description need not reconstruct the representation exactly, provided that it satisfies the informational condition required for extendedness. The definition does not imply that the hypothesis has been discovered or considered within scientific practice. It characterizes the theoretical space of representation--description pairs satisfying the requirements of the theory.

In many scientific applications, the representation is fixed in advance. For example, an experimental dataset may be given, and the objective is to identify a mathematical model capable of accounting for the information it contains. In such situations, it is convenient to restrict attention to hypotheses associated with the given representation.

\begin{definition}
\label{def:hypotheses_for_representation}
Let $r\in\mathcal{R}$ be a representation. We define the \emph{set of hypotheses of $r$}\index{Hypothesis!of a representation}, denoted by $\mathcal{H}_r$, as
\[
\mathcal{H}_r = \left\{(r,d)\in\mathcal{H} \;\middle|\; d\in\mathcal{D}_r \right\}.
\]
\end{definition}

Equivalently,
\[
\mathcal{H}_r=\{r\}\times\mathcal{D}_r.
\]
The set $\mathcal{H}_r$ contains all hypotheses sharing the same representation, while allowing their descriptions to vary. Since every finite representation admits an exact description, and every exact description is extended, we have $\mathcal{H}_r\neq\varnothing$ for every $r\in\mathcal{R}$.

An important structural property is that the representation-specific hypothesis sets form a partition of the global hypothesis space.

\begin{proposition}
\label{prop:hypothesis_rep_partition}
The set of hypotheses satisfies
\[
\mathcal{H} = \bigcup_{r\in\mathcal{R}}\mathcal{H}_r.
\]
Moreover, for any two distinct representations $r_1,r_2\in\mathcal{R}$,
\[
\mathcal{H}_{r_1}\cap\mathcal{H}_{r_2} = \varnothing.
\]
\end{proposition}

\begin{proof}
By definition, every hypothesis $(r,d)\in\mathcal{H}$ has a representation $r\in\mathcal{R}$ and a description $d\in\mathcal{D}_r$. Hence $(r,d)\in\mathcal{H}_r$, establishing the stated union.

For the second statement, suppose that
\[
(r,d)\in\mathcal{H}_{r_1}\cap\mathcal{H}_{r_2}.
\]
Then the first component of the pair must equal both $r_1$ and $r_2$, implying $r_1=r_2$. Therefore, if $r_1\neq r_2$, the intersection is empty.
\end{proof}

This proposition shows that every hypothesis belongs to exactly one representation-specific hypothesis set. This remains true even when two distinct representations share extended descriptions, since the corresponding hypotheses differ in their representational components.

Scientific inquiry, however, is usually directed toward understanding entities rather than fixed representations. Since an entity may admit several extended representations, we introduce the corresponding entity-specific hypothesis space.

\begin{definition}
\label{def:hypotheses_for_entity}
Let $e\in\mathcal{E}$ be an entity. We define the \emph{set of hypotheses of $e$}\index{Hypothesis!of an entity}, denoted by $\mathcal{H}_e$, as
\[
\mathcal{H}_e = \left\{(r,d)\in\mathcal{H} \;\middle|\; r\in\mathcal{R}_e \right\}.
\]
\end{definition}

Thus, a hypothesis belongs to $\mathcal{H}_e$ whenever its representation contains the information required to qualify as an extended representation of $e$, and its description belongs to the corresponding extended-description set.

By definition,
\[
\mathcal{H}_e = \bigcup_{r\in\mathcal{R}_e}\mathcal{H}_r.
\]
Consequently,
\[
\mathcal{H}_r \subseteq \mathcal{H}_e \subseteq \mathcal{H}, \qquad r\in\mathcal{R}_e.
\]
A representation-specific hypothesis space contains alternative descriptions of a fixed representation, whereas an entity-specific hypothesis space allows both the representation and its description to vary. Moreover, since every extended representation admits at least one extended description,
\[
\mathcal{H}_e\neq\varnothing \quad\Longleftrightarrow\quad \mathcal{R}_e\neq\varnothing.
\]
This establishes that the existence of theoretical hypotheses for an entity depends on the existence of extended representations of that entity.

Recall that the global representation space satisfies
\[
\mathcal{R} = \bigcup_{e\in\mathcal{E}}\mathcal{R}_e.
\]
It follows immediately that
\[
\mathcal{H} = \bigcup_{e\in\mathcal{E}}\mathcal{H}_e.
\]
Unlike the representation-specific hypothesis sets, however, the entity-specific hypothesis sets need not be disjoint. This difference arises because a single extended representation may contain information about several distinct entities. The following proposition characterizes the possible overlap.

\begin{proposition}
\label{prop:hypothesis_entity_intersection}
Let $e_1,e_2\in\mathcal{E}$ be two entities. Then
\[
\mathcal{H}_{e_1}\cap\mathcal{H}_{e_2} = 
\bigcup_{r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}} \mathcal{H}_r.
\]
Consequently,
\[
\mathcal{H}_{e_1}\cap\mathcal{H}_{e_2} \neq\varnothing \quad\Longleftrightarrow\quad
\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2} \neq\varnothing.
\]
\end{proposition}
\begin{proof}
Let $(r,d)\in\mathcal{H}_{e_1}\cap\mathcal{H}_{e_2}$. By definition $r\in\mathcal{R}_{e_1}$ and $r\in\mathcal{R}_{e_2}$. Hence $r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}$. Since $d\in\mathcal{D}_r$, we have $(r,d)\in\mathcal{H}_r$, proving the first inclusion.

Conversely, suppose that
\[
(r,d) \in \bigcup_{s\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}} \mathcal{H}_s.
\]
Then $r\in\mathcal{R}_{e_1}\cap\mathcal{R}_{e_2}$ and $d\in\mathcal{D}_r$. Therefore $(r,d)\in\mathcal{H}_{e_1}$ and $(r,d)\in\mathcal{H}_{e_2}$, which establishes the equality.

The final equivalence follows because every representation in $\mathcal{R}$ admits at least one extended description, and hence at least one hypothesis.
\end{proof}

This proposition shows that a hypothesis need not be associated with a unique entity. If its representation contains information about several entities, the same representation--description pair may belong to several entity-specific hypothesis spaces. 4For example, an experimental dataset may contain information about several related physical phenomena. A mathematical model describing a regularity in that dataset may consequently contribute to hypotheses concerning more than one entity.

This distinction will become important when introducing nescience. Although the same hypothesis may be associated with several entities, the adequacy of its representation must be evaluated relative to the particular entity under investigation. By contrast, the quality of the description concerns its relationship with the representation itself. In particular, for a hypothesis $(r,d)$ associated with an entity $e$, these two aspects will be evaluated through $\mu_e(r)$ and $\nu_r(d)$, where $\mu_e(r)$ denotes miscoding and $\nu_r(d)$ denotes mismodel. Thus, the same hypothesis may have different miscoding values, and consequently different nescience, depending on the entity with respect to which it is evaluated.

% Subsection: Known Hypotheses

\subsection*{Known Hypotheses}
\label{subsec:known_hypotheses}

The theoretical set $\mathcal{H}$ contains all representation--description pairs satisfying the informational requirements established by the theory. However, this set is generally inaccessible in scientific practice, since it depends on the theoretical sets of extended representations and descriptions. Scientists work instead with hypotheses that have actually been proposed, investigated, or adopted within existing scientific frameworks. These hypotheses may provide useful explanations, contain only limited information, or be entirely incorrect. We refer to them as \emph{known hypotheses}.

\begin{definition}
\label{def:known_hypotheses}
We define the \emph{set of known hypotheses}\index{Known hypotheses} at time $t$, denoted by $\hat{\mathcal{H}}^t$, as
\[
\hat{\mathcal{H}}^t = \left\{(r,d) \in \hat{\mathcal{R}}^t\times\mathcal{D}^\top 
\;\middle|\; d\in\hat{\mathcal{D}}_r^t \right\}.
\]
\end{definition}

Thus, a known hypothesis is a pair consisting of an effective representation and a decodable description that has been considered as a model of that representation within scientific practice. The definition does not require the representation to belong to $\mathcal{R}$ or the description to belong to $\mathcal{D}_r$. Consequently, a known hypothesis need not satisfy the theoretical requirements defining $\mathcal{H}$.

This distinction is fundamental. The set $\mathcal{H}$ contains theoretically informative representation--description pairs, whereas $\hat{\mathcal{H}}^t$ records those that have entered scientific consideration, regardless of their informational adequacy. The pairs that are both known and theoretically informative hypotheses belong to $\hat{\mathcal{H}}^t\cap\mathcal{H}$. In general, however, membership of a known hypothesis in $\mathcal{H}$ cannot be determined effectively, since the relevant representational and descriptive conditions depend on theoretical quantities that are not computable in general.

The correspondence between known hypotheses and effective descriptions follows directly from their definitions:
\[
\hat{\mathcal{D}}^t = \left\{ d\in\mathcal{D}^\top \;\middle|\; 
\exists r\in\hat{\mathcal{R}}^t: (r,d)\in\hat{\mathcal{H}}^t \right\}.
\]
Thus, the global set of effective descriptions can be recovered from the descriptive components of known hypotheses. The hypothesis space, however, retains additional information: it records which descriptions have been associated with which representations.

As with theoretical hypotheses, it is useful to consider the known hypotheses associated with a particular entity.

\begin{definition}
\label{def:known_hypotheses_entity}
Let $e\in\mathcal{E}$ be an entity. We define the \emph{set of known hypotheses of $e$}\index{Known hypotheses!of an entity} at time $t$, denoted by $\hat{\mathcal{H}}_e^t$, as
\[
\hat{\mathcal{H}}_e^t = \left\{(r,d)\in\hat{\mathcal{H}}^t \;\middle|\; r\in\hat{\mathcal{R}}_e^t \right\}.
\]
\end{definition}

The set $\hat{\mathcal{H}}_e^t$ collects the known representation--description pairs associated with effective representations of the entity $e$.

These associations must be interpreted historically. Since both effective representations and effective descriptions are defined cumulatively, a pair may belong to $\hat{\mathcal{H}}_e^t$ even if the description was not explicitly proposed as an explanation of $e$ at the time it was originally formulated. For example, a representation may initially be associated with one entity and later be reinterpreted as representing another. Descriptions previously associated with that representation then belong to the derived hypothesis sets of both entities under the cumulative convention. This does not imply that each description was explicitly proposed as a hypothesis about both entities.

The set $\hat{\mathcal{H}}_e^t$ therefore characterizes the hypotheses associated with an entity through historical representation--description relationships, rather than requiring a separate record of explicit entity-level proposals.

The relationship between known hypotheses and effective descriptions of an entity follows directly from their definitions:
\[
\hat{\mathcal{D}}_e^t = \left\{d\in\mathcal{D}^\top \;\middle|\; 
\exists r\in\hat{\mathcal{R}}_e^t: (r,d)\in\hat{\mathcal{H}}_e^t \right\}.
\]
Consequently,
\[
\hat{\mathcal{H}}_e^t\neq\varnothing \quad\Longleftrightarrow\quad \hat{\mathcal{D}}_e^t\neq\varnothing.
\]
Furthermore, since every known hypothesis of an entity contains an effective representation of that entity,
\[
\hat{\mathcal{H}}_e^t\neq\varnothing \quad\Longrightarrow\quad \hat{\mathcal{R}}_e^t\neq\varnothing.
\]
The converse does not necessarily hold. An entity may have entered scientific consideration through one or more effective representations before any computational description has been associated with them. Thus, the existence of a known hypothesis distinguishes entities for which scientific practice has developed at least one descriptive account from those for which representations have been proposed but no corresponding description has yet been recorded.

% Subsection: Evolution of Known Hypotheses

\subsection*{Evolution of Known Hypotheses}

Scientific hypotheses evolve over time as new representations and descriptions are proposed, existing models are refined, and previously accepted explanations are rejected or superseded. As scientific inquiry progresses, the collection of hypotheses that have been considered expands, while their scientific status may change. As in the preceding sections on effective representations and descriptions, we distinguish the cumulative historical record from the collection of hypotheses that remain under active scientific consideration.

Both effective representations and effective descriptions are defined cumulatively: once a representation has been considered, or a description has been associated with a representation, that historical association remains recorded even if it is subsequently rejected or superseded. These properties determine the temporal evolution of known hypotheses.

\begin{proposition}
\label{prop:known_hypotheses_monotonic}
Let $t_1<t_2$. Then
\[
\hat{\mathcal{H}}^{t_1} \subseteq \hat{\mathcal{H}}^{t_2}.
\]
Moreover, for every fixed entity $e\in\mathcal{E}$,
\[
\hat{\mathcal{H}}_e^{t_1} \subseteq \hat{\mathcal{H}}_e^{t_2}.
\]
\end{proposition}
\begin{proof}
Let $(r,d)\in\hat{\mathcal{H}}^{t_1}$. By definition $r\in\hat{\mathcal{R}}^{t_1}$ and $d\in\hat{\mathcal{D}}_r^{t_1}$. By the monotonicity of effective representations and effective descriptions $\hat{\mathcal{R}}^{t_1} \subseteq \hat{\mathcal{R}}^{t_2}$ and $\hat{\mathcal{D}}_r^{t_1} \subseteq \hat{\mathcal{D}}_r^{t_2}$. Consequently $r\in\hat{\mathcal{R}}^{t_2}$ and $d\in\hat{\mathcal{D}}_r^{t_2}$, which implie $(r,d)\in\hat{\mathcal{H}}^{t_2}$. Therefore $\hat{\mathcal{H}}^{t_1} \subseteq \hat{\mathcal{H}}^{t_2}$.

For the second statement, let $(r,d)\in\hat{\mathcal{H}}_e^{t_1}$. By definition $(r,d)\in\hat{\mathcal{H}}^{t_1}$ and $r\in\hat{\mathcal{R}}_e^{t_1}$. The first inclusion established above gives $(r,d)\in\hat{\mathcal{H}}^{t_2}$. Moreover, by the monotonicity of effective representations of an entity $\hat{\mathcal{R}}_e^{t_1} \subseteq \hat{\mathcal{R}}_e^{t_2}$. Hence $r\in\hat{\mathcal{R}}_e^{t_2}$ Therefore $(r,d)\in\hat{\mathcal{H}}_e^{t_2}$, which establishes the second inclusion.
\end{proof}

This proposition formalizes the cumulative character of scientific exploration. Once a hypothesis has been considered, it remains part of the historical record, even if subsequent evidence leads to its rejection. The same property holds for the known hypotheses associated with any fixed entity, provided that historical representation--entity and representation--description associations are retained. However, the expansion of the known-hypothesis set does not necessarily imply an improvement in scientific understanding. New hypotheses may be informative, redundant, misleading, or entirely incorrect. Their introduction expands the range of explanations explored, but does not guarantee a reduction in miscoding, mismodel, or nescience.

\section{Models}
\label{sec:models}

Descriptions are computational objects capable of generating finite binary strings. As established in Section~\ref{sec:decodable_descriptions}, each decodable description has the form $d=\langle TM,a\rangle$, where $TM$ is a Turing machine and $a$ is an input string on which the computation halts. Although this computational framework is extremely general, it presents two important limitations for scientific inquiry. First, the set of decodable descriptions $\mathcal{D}^\top$ constitutes an enormous search space, containing computational procedures of arbitrary complexity and structure. Identifying suitable descriptions within this space is therefore a difficult problem, and an exhaustive search is generally impractical. Second, computational descriptions are not necessarily suitable for mathematical reasoning. Although every decodable description produces a well-defined output, its underlying procedure may be difficult to interpret or manipulate algebraically. In particular, an arbitrary computational description may support the prediction of a phenomenon without providing mathematical relationships that can be readily transformed, simplified, or used to derive solutions to related problems.

To address these limitations, scientific inquiry frequently restricts attention to descriptions characterized by common mathematical structures, such as algebraic equations, differential equations, or systems of mathematical relationships. These restrictions reduce the space of candidate descriptions while providing structures that may facilitate mathematical analysis, explanation, and problem-solving. We refer to such restricted families of descriptions as \emph{model classes}.

Mathematical models are therefore treated as computational descriptions satisfying additional structural restrictions, rather than as a separate fundamental element of the theory. Consequently, all the definitions and properties established for descriptions, including exactness, minimality, extendedness, and effectiveness, remain applicable to mathematical models.

% Subsection: Model Classes

\subsection*{Model Classes}

A mathematical model specifies a relationship between variables, often expressed through an equation or a system of equations. Examples include equations of state, adsorption isotherms, kinetic laws, and differential equations describing the evolution of physical or biological systems. Such mathematical relationships can be implemented by computational procedures, provided that their inputs and outputs are encoded appropriately and the relevant computations terminate. Different descriptions may share the same mathematical structure while differing in their parameter values or other computational details. This motivates the following definition.

\begin{definition}
\label{def:model_class}
We define a \emph{model class}\index{Model class} as a subset
\[
\mathcal{M}\subseteq\mathcal{D}^\top
\]
whose elements satisfy a specified common mathematical or computational structural constraint. Each description $d\in\mathcal{M}$ is called a \emph{model instance}.
\end{definition}

A model class restricts the space of decodable descriptions to those conforming to a particular structure. For example, one class may contain descriptions implementing linear relationships, while another contains descriptions implementing a particular equation of state.

The definition does not require descriptions in $\mathcal{M}$ to be exact, minimal, or extended descriptions of any particular representation. A model may have been formulated according to a valid mathematical structure while failing to describe the observations for which it was proposed. Consequently, model classes are defined as subsets of $\mathcal{D}^\top$, rather than the more restrictive set $\mathcal{D}$ of extended descriptions.

The distinction between models and hypotheses is important. A model instance is a computational description, whereas a hypothesis associates a description with a particular representation. Thus, a model instance $d\in\mathcal{M}$ can participate in different hypotheses, depending on the representation it is intended to describe.

\begin{notation}
Let $\mathcal{M}\subseteq\mathcal{D}^\top$ be a model class. We denote by $\mathcal{H}_{\mathcal{M}}$ the set of theoretical hypotheses whose descriptions belong to $\mathcal{M}$:
\[
\mathcal{H}_{\mathcal{M}} = \left\{(r,d)\in\mathcal{H} : d\in\mathcal{M} \right\}.
\]
Similarly, we denote by $\hat{\mathcal{H}}_{\mathcal{M}}^t$ the set of known hypotheses involving descriptions from $\mathcal{M}$ at time $t$:
\[
\hat{\mathcal{H}}_{\mathcal{M}}^t = \left\{(r,d)\in\hat{\mathcal{H}}^t : d\in\mathcal{M} \right\}.
\]
\end{notation}

These constructions introduce no additional requirements on hypotheses. They simply restrict the hypothesis spaces defined in Section~\ref{sec:hypotheses} to descriptions belonging to a chosen model class.

% Subsection: Parametric Models

\subsection*{Parametric Models}

An important family of mathematical models consists of those whose structure is fixed while their behavior depends on a collection of parameters. These are called \emph{parametric models}. A parametric mathematical model may be specified by an equation containing unknown constants. Choosing particular values for those constants determines a specific instance of the model, which can then be applied to different inputs.

Within the computational framework of descriptions, this distinction can be represented by a Turing machine implementing the mathematical structure, together with an encoding of its parameters. The resulting parameterized machine constitutes a model that can be applied to different inputs, each application giving rise to a decodable description.

\begin{definition}
\label{def:parametric_model}
Let $TM_m$ be a fixed computational implementation of a mathematical model structure, and let $\Theta_m$ be a set of finitely encodable parameter values. For each $\theta\in\Theta_m$, let $\langle\theta\rangle_m\in\mathcal{B}^\ast$ denote its binary encoding under a fixed, effective, uniquely decodable encoding convention associated with the model class $m$. We define the \emph{parameterized model} corresponding to $\theta$ as
\[
M_\theta = \langle TM_m,\langle\theta\rangle_m\rangle,
\]
where the encoding denotes the permitted Turing machine obtained by specializing $TM_m$ to the parameter values $\theta$ through a fixed computable procedure.

Let $\mathcal{A}_m\subseteq\mathcal{B}^\ast$ be a set of admissible input strings. We assume that each $M_\theta$ is a permitted prefix-free Turing machine and that $M_\theta(a)\downarrow$ for every $a\in\mathcal{A}_m$. We define the \emph{parametric model class}\index{Parametric model} associated with $TM_m$ as
\[
\mathcal{M}_m = \left\{d_{\theta,a}=\langle M_\theta,a\rangle : \theta\in\Theta_m,\; a\in\mathcal{A}_m \right\}.
\]
\end{definition}

In this definition, $TM_m$ specifies the common mathematical structure, $\theta$ determines a particular parameterized model $M_\theta$, and $a$ contains the input to which that model is applied. The inner encoding $\langle TM_m,\langle\theta\rangle_m\rangle$ denotes a specialized Turing machine, whereas the outer encoding $\langle M_\theta,a\rangle$ is a decodable description in the sense established earlier in this chapter. For every description $d_{\theta,a}=\langle M_\theta,a\rangle$ belonging to the parametric model class, the description function produces the output of the parameterized model applied to its input:
\[
\Gamma(d_{\theta,a}) = M_\theta(a) = TM_m(\langle\langle\theta\rangle_m,a\rangle).
\]
Thus, $\Gamma(d_{\theta,a})$ is a finite binary string encoding the result obtained by evaluating the mathematical model with parameters $\theta$ on input $a$. Depending on the model, this output may represent a numerical prediction, a sequence of predicted values, or another computational result.

Since every description in the model class encodes a permitted Turing machine that halts on its specified input, we have
\[
\mathcal{M}_m\subseteq\mathcal{D}^\top.
\]

The distinction between model parameters and model inputs is important. A particular mathematical model may be applied to different experimental conditions without modifying its structure or parameters. Conversely, different parameter values may define alternative models that can be evaluated under the same experimental conditions.

The requirement that parameters admit finite encodings is essential. Although mathematical models are often formulated using real-valued parameters, arbitrary real numbers cannot be represented exactly by finite binary strings. Consequently, the computational descriptions considered here must employ finitely representable parameter values, such as rational numbers or numerical values encoded at a specified precision. Likewise, the application of a mathematical model must produce a finite binary output. When a formula involves real-valued computations, its implementation may therefore require numerical precision, rounding conventions, or terminating approximation procedures. These conventions are part of the computational realization of the mathematical model and ensure that the resulting descriptions are well defined.

\begin{example}
\label{ex:langmuir_model}
Consider the Langmuir adsorption isotherm, which describes the amount of a substance adsorbed onto a surface as a function of its equilibrium pressure. The model is given by
\[
q(P) = \frac{q_{\max}KP}{1+KP},
\]
where $P$ is the equilibrium pressure, $q(P)$ is the adsorbed amount, $q_{\max}$ is the maximum adsorption capacity, and $K$ is an equilibrium constant. The mathematical structure is fixed, while the parameters $\theta=(q_{\max},K)$ determine a particular instance of the model.

Let $TM_{\mathrm{Lang}}$ implement the Langmuir equation, and let $\Theta_{\mathrm{Lang}}=\mathbb{Q}_{>0}^2$ be the parameter space consisting of positive rational pairs, equipped with a fixed effective encoding. For each $\theta\in\Theta_{\mathrm{Lang}}$, the corresponding parameterized model is
\[
M_\theta
=
\langle
TM_{\mathrm{Lang}},
\langle\theta\rangle_{\mathrm{Lang}}
\rangle.
\]
Suppose that experimental measurements are available at a finite collection of positive rational pressures $P_1,P_2,\ldots,P_n$. These pressures are encoded as an input string $a=\langle P_1,\ldots,P_n\rangle$, using a fixed self-delimiting encoding. Applying the model $M_\theta$ to this input gives the decodable description
\[
d_{\theta,a} = \langle M_\theta,a\rangle.
\]
The description function produces a finite encoding of the predicted adsorption values:
\[
\Gamma(d_{\theta,a})
=
\left\langle
\hat q_\theta(P_1),
\ldots,
\hat q_\theta(P_n)
\right\rangle,
\]
where
\[
\hat q_\theta(P_i)
=
\frac{q_{\max}KP_i}{1+KP_i}.
\]
Since the parameters and pressures are rational and the denominators are positive, these predictions are rational and can be computed and encoded exactly.

Let $r$ be the binary representation of the experimentally observed adsorption values at the same pressures, using the corresponding output encoding. In general $\Gamma(d_{\theta,a})\neq r$, because the mathematical model may not reproduce the observations exactly. Nevertheless, if $r\in\mathcal{R}$, the description may qualify as an extended description of $r$ whenever it satisfies the informational condition established in Section~\ref{sec:extended_descriptions}. Alternatively, it may be an effective description that has entered scientific practice without satisfying that condition.

The same parameterized model $M_\theta$ can be applied to different collections of experimental pressures, producing different descriptions. Likewise, different parameter values may be considered for the same experimental input, producing competing descriptions of the observed representation.
\end{example}

This example illustrates how parametric mathematical models fit naturally into the existing descriptive framework. The mathematical structure is implemented by a Turing machine, the model parameters determine a specialized machine, and the input specifies the conditions under which the model is evaluated. The resulting computational object is a decodable description whose output can be compared with an experimental representation. The same construction applies to other mathematical models, including equations of state, kinetic laws, and systems of differential equations. More elaborate models may require numerical solvers or additional computational procedures, but they remain subject to the same definitions and properties established for descriptions.

Restricting descriptions to a model class limits the mathematical structures available for modeling a representation. Such restrictions may simplify the search for suitable descriptions and facilitate mathematical reasoning, but they may also exclude descriptions that capture relevant regularities more effectively. In particular, a model class $\mathcal{M}$ need not contain any exact description of a given representation $r$, even though exact descriptions always exist in the unrestricted descriptive space. Likewise, a model class may contain extended descriptions of $r$ without containing any of its minimal descriptions. Consequently, restricting the descriptive space may prevent the discovery of descriptions that are more accurate or economical. Different model classes may provide alternative descriptions of the same representation. For example, observations of a physical phenomenon may be described using different mathematical laws, each characterized by its own structural assumptions and parameters. These competing descriptions can be evaluated using the same measures of mismodel, inaccuracy, and surfeit introduced in subsequent chapters. Thus, model classes provide a practical way to organize scientific descriptions without changing their fundamental properties. Their purpose is not to guarantee descriptive optimality, but to make particular mathematical structures available for investigation, comparison, and refinement.

\section{Operations on Descriptions}

Augmentation and reduction are two complementary operations on descriptions. Augmentation models the idea of enriching a description by supplying additional computable information that may be missing from the original one. Reduction models the opposite process: simplifying a description by separating out information that is not needed for the purpose at hand. Together, these operations provide a basic formal vocabulary for describing how scientific descriptions may be refined, expanded, or simplified over time.

These operations are introduced here at a purely structural level. Their purpose is not yet to determine whether a description has improved, or whether a particular transformation brings it closer to an ideal description. Rather, they formalize two elementary ways of modifying descriptions: by adding information through augmentation, and by removing information through reduction. In both cases, the result is required to remain within the domain of valid descriptions, so that the transformed object continues to be interpretable as a computable description.

This distinction is important because the same formal operation may have very different effects depending on the context. An augmentation may add genuinely useful information, but it may also introduce irrelevant detail. Likewise, a reduction may remove superfluous structure, but it may also discard information that later proves important. For this reason, augmentation and reduction are best understood at this stage as general operations on descriptions. Their role in decreasing deficiency, surplus, or mismodel will be examined in Chapter \ref{chap:Mismodel}, once those defects have been formally defined.

% Subsection: Operation of Augmentation


\subsection*{Operation of Augmentation}

A description may fail to account for all the information contained in its intended representation. One way to address this limitation is to enrich the description with additional information, such as new mathematical relationships, computational rules, or corrections to an existing model. We call this operation \emph{augmentation}.

Augmentation of descriptions is analogous to the augmentation of representations introduced in Section~\ref{sec:joint_representations}. In both cases, the purpose is to incorporate information that may be missing from the original object. However, whereas augmentation of representations operates directly on binary strings, augmentation of descriptions combines computational objects and may modify the procedures they encode.

The fundamental requirement of augmentation is that the information contained in the original description must remain recoverable from the resulting description. Augmentation may introduce new information or reorganize existing computational structures, but it must not discard the algorithmic information contained in the original description. Since not every auxiliary description need be suitable for augmenting every original description, we introduce augmentation as a partial computable operation.

\begin{definition}
\label{def:augmentation_descriptions}
\label{def:information_preserving_augmentation}
An \emph{augmentation operator}\index{Augmentation operator} is a partial computable function
\[
\operatorname{aug}: \mathcal{D}^\top\times\mathcal{D}^\top \rightharpoonup\mathcal{D}^\top
\]
for which there exists a fixed partial computable function
\[
p:\mathcal{D}^\top\rightharpoonup\mathcal{D}^\top
\]
such that, for every $d,a\in\mathcal{D}^\top$ for which $\operatorname{aug}(d,a)$ is defined,
\[
p(\operatorname{aug}(d,a))=d.
\]
Whenever $\operatorname{aug}(d,a)$ is defined, the resulting description $\operatorname{aug}(d,a)$ is called an \emph{augmentation}\index{Augmentation of descriptions} of $d$ by $a$, and $a$ is called an \emph{augmentation description}\index{Augmentation description}.
\end{definition}

The operator constructs a new description by incorporating information from an auxiliary description into an existing one. The definition does not prescribe a particular method of combination, allowing different augmentation operators to be employed according to the computational structures under consideration. A particular operator is assumed to be fixed whenever its properties are investigated.

Augmentation is defined over decodable descriptions rather than entity-dependent sets such as $\mathcal D_e$, because it is a general computational operation independent of any particular entity. Moreover, membership in $\mathcal D_e$ is generally undecidable, so restricting augmentation to this set would complicate its computability. Unlike augmentation of representations, which is defined over $\mathcal{R}_{e}$, descriptive augmentation may combine any two decodable descriptions. Whenever defined, it produces another decodable description, whose relationship with a particular entity or target representation must be established separately.

The recoverability requirement ensures that the original description can be reconstructed effectively from the augmented description. The recovery procedure is fixed and does not depend on the particular arguments. This uniformity is essential: allowing a different recovery procedure for each augmentation would not establish a uniform bound on conditional Kolmogorov complexity, since the recovery procedure could itself encode the description to be recovered.

The following proposition establishes the fundamental algorithmic
properties of augmentation.

\begin{proposition}
\label{prop:augmentation_information_preservation}
Let $\operatorname{aug}$ be an augmentation operator, and let $d,a\in\mathcal{D}^\top$ be such that
$\operatorname{aug}(d,a)$ is defined. Then
\[
K(\operatorname{aug}(d,a)\mid d,a)=O(1)
\]
and
\[
K(d\mid\operatorname{aug}(d,a))=O(1).
\]
\end{proposition}
\begin{proof}
Since $\operatorname{aug}$ is a fixed partial computable function, a program of constant length can compute $\operatorname{aug}(d,a)$ from the pair $(d,a)$ whenever the operation is defined. Therefore,
\[
K(\operatorname{aug}(d,a)\mid d,a)=O(1).
\]
By Definition~\ref{def:augmentation_descriptions}, there exists a fixed partial computable recovery function $p$
such that
\[
p(\operatorname{aug}(d,a))=d.
\]
Consequently, a program of constant length can recover$d$ from $\operatorname{aug}(d,a)$, giving
\[
K(d\mid\operatorname{aug}(d,a))=O(1).
\]
\end{proof}

The proposition shows that augmentation preserves the algorithmic information contained in the original description, up to an additive constant. In particular,
\[
K(d)\le K(\operatorname{aug}(d,a))+O(1).
\]
However, the auxiliary description need not remain recoverable, since augmentation may incorporate only part of its information.

Information preservation does not imply preservation of the original output. In general,
\[
\Gamma(\operatorname{aug}(d,a)) \neq \Gamma(d).
\]
The augmented description may implement a different computational procedure and produce a different representation. Furthermore, augmentation need not increase the length of the description, since recoverability constrains algorithmic information rather than literal length.

Augmentation also does not necessarily preserve the relationship between a description and its target representation. In particular,
\[
d\in\mathcal D_r \quad\not\Rightarrow\quad \operatorname{aug}(d,a)\in\mathcal D_r.
\]
Although the original description remains recoverable, the output of the augmented description may no longer contain sufficient information about $r$. Membership in $\mathcal D_r$ must therefore be established separately.

Finally, augmentation does not guarantee an improvement in descriptive quality. When both descriptions belong to $\mathcal D_r$, information preservation ensures that deficiency cannot increase substantially, but also that existing surplus cannot decrease substantially. An augmentation may therefore reduce deficiency while increasing surplus, without necessarily reducing mismodel. These effects will be examined in Chapter~\ref{chap:Mismodel}.

\begin{example}
Consider a representation $r$ encoding observations of the trajectory of a projectile. Let $d=\langle TM_1,a_1\rangle$ be a decodable description implementing projectile motion in vacuum, with initial conditions encoded in $a_1$- Let $a=\langle TM_2,a_2\rangle$ be an auxiliary description modeling aerodynamic drag.
Suppose that an augmentation operator combines both models, producing $d^+=\operatorname{aug}(d,a)$. The augmented description implements equations of motion that account for air resistance. Consequently, its output generally differs from that of the original description: $\Gamma(d^+)\neq\Gamma(d)$. Nevertheless, $d$ must remain recoverable from $d^+$ by a fixed computable procedure. For example, $d^+$ may contain a recoverable encoding of the original model alongside the modified computational procedure. The auxiliary description $a$, however, need not be recoverable in its entirety. If aerodynamic drag is relevant to the observed trajectory, the augmented model may provide a better account of the observations. However, improved agreement does not by itself establish that descriptive deficiency or mismodel has decreased.
\end{example}

Augmentation thus incorporates additional information while preserving the original description. Its effects on descriptive deficiency and surplus, and its contribution to decreasing nescience, will be examined in the corresponding chapters.

% Subsection: Operation of Reduction

\subsection*{Operation of Reduction}

A description may contain computational structures, parameters, or other information that is unnecessary for its intended purpose. One way to simplify the description is to remove some of this information while retaining the possibility of reconstructing the original description. We call this operation \emph{reduction}.

Reduction of descriptions is analogous to the reduction of representations introduced in Section~\ref{sec:joint_representations}. In both cases, an existing object is decomposed into a retained component and a discarded component. However, whereas reduction of representations removes symbols from a binary string, reduction of descriptions operates on computational objects and may modify the procedures they encode.

We define reduction as a partial computable operation that decomposes a description into two decodable descriptions. The original description must be recoverable from the resulting components by a fixed computable procedure.

\begin{definition}
\label{def:reduction_descriptions}
A \emph{reduction operator}\index{Reduction operator} is a partial computable function
\[
\operatorname{red}: \mathcal D^\top \rightharpoonup \mathcal D^\top\times\mathcal D^\top
\]
for which there exists a fixed partial computable function
\[
p: \mathcal D^\top\times\mathcal D^\top \rightharpoonup \mathcal D^\top
\]
such that, whenever $\operatorname{red}(d)=(d_1,a)$ is defined, the following conditions hold:
\begin{enumerate}[label=\roman*]
    \item $\ell(d_1)\leq\ell(d)$,
    \item $p(d_1,a)=d$.
\end{enumerate}

The description $d_1$ is called the
\emph{reduced description}\index{Reduced description}
of $d$, and $a$ is called the
\emph{discarded description}\index{Discarded description}.
\end{definition}

The first condition requires that the reduced description be no longer than the original. The second guarantees that the original description can be reconstructed exactly from the reduced and discarded descriptions, including its computational structure and encoding. The reconstruction function is fixed and does not depend on the particular description being reduced. This ensures that reconstruction requires only constant computational description overhead. Reduction is defined independently of augmentation. Although the two operations are complementary, the reconstruction function associated with reduction need not coincide with any previously defined augmentation operator. This allows different reduction operators to implement different ways of decomposing the same description.

The definition imposes no restriction on the combined length of the resulting components. In particular, it is possible that $\ell(d_1)+\ell(a)>\ell(d)$. Reduction should therefore not be confused with lossless compression of the complete description. Its purpose is to obtain a potentially simpler retained description while separating the information needed to reconstruct the original.

Reduction preserves the complete algorithmic information of the original description when both resulting components are considered together. However, retaining only the reduced description may result in a loss of information. The following proposition characterizes these relationships.

\begin{proposition}
\label{prop:reduction_information}
Let $\operatorname{red}$ be a reduction operator, and suppose that $\operatorname{red}(d)=(d_1,a)$, then
\[
K(d_1,a\mid d)=O(1)
\]
and
\[
K(d\mid d_1,a)=O(1).
\]
Consequently,
\[
K(d)=K(d_1,a)+O(1).
\]
Furthermore,
\[
K(d_1\mid d)=O(1)
\]
and
\[
K(d\mid d_1)=K(a\mid d_1)+O(1).
\]
\end{proposition}
\begin{proof}
Since reduction is a fixed partial computable operation, both resulting components can be obtained from the original description with constant overhead:
\[
K(d_1,a\mid d)=O(1).
\]
Conversely, the reconstruction condition guarantees that $p(d_1,a)=d$. Since $p$ is a fixed partial computable function,
\[
K(d\mid d_1,a)=O(1).
\]
Thus, the original description and the pair of resulting components are mutually computable with constant overhead, which implies
\[
K(d)=K(d_1,a)+O(1).
\]
Moreover, since $d_1$ can be obtained by executing the reduction operator on $d$,
\[
K(d_1\mid d)=O(1).
\]
To establish the final equality, observe that $d$ can be reconstructed from $d_1$ once $a$ is supplied. Therefore,
\[
K(d\mid d_1) \leq K(a\mid d_1) + O(1).
\]
Conversely, given $d$, one can execute the reduction operator to recover $a$. Hence,
\[
K(a\mid d_1) \leq K(d\mid d_1)+O(1).
\]
Combining both inequalities gives
\[
K(d\mid d_1)=K(a\mid d_1)+O(1).
\]
\end{proof}

The proposition establishes that reduction does not destroy algorithmic information when both components are retained. Instead, it separates the information contained in the original description into two jointly sufficient components.

The quantity $K(a\mid d_1)$ characterizes, up to an additive constant, the algorithmic information required to reconstruct the original description from the reduced one. This quantity need not correspond to the literal length of the discarded description. A large discarded component may contain little information not already recoverable from the reduced description. Conversely, a small discarded component may contain information essential to reconstructing the original.

Reduction may be applied repeatedly whenever each successive operation is defined. If
\[
\begin{aligned}
\operatorname{red}(d)&=(d_1,a_1),\\
\operatorname{red}(d_1)&=(d_2,a_2),\\
&\ \vdots\\
\operatorname{red}(d_{n-1})&=(d_n,a_n),
\end{aligned}
\]
then the defining length condition gives
\[
\ell(d_n)\leq\ell(d_{n-1})
\leq\cdots\leq\ell(d_1)\leq\ell(d).
\]
Thus, successive reductions produce a non-increasing sequence of reduced-description lengths. However, the reductions need not be strict, so repeated application is not guaranteed to terminate. If every step strictly decreases length, only finitely many steps are possible.

Reduction does not necessarily preserve the output of the original description. In general,
\[
\operatorname{red}(d)=(d_1,a) \quad\not\Rightarrow\quad \Gamma(d_1)=\Gamma(d).
\]
Removing computational structures or parameters may alter the behavior of the reduced description, producing
a different output. In particular, if $d$ is a minimal description of a representation $r$, any reduction producing a strictly shorter description $d_1$ must satisfy $\Gamma(d_1)\neq r$. Otherwise, $d_1$ would be a shorter exact description of $r$, contradicting the minimality of $d$.

Reduction is therefore defined independently of the relationship between a description and its intended representation. The reduced description need not remain an extended description of the same target, nor is it guaranteed to have lower descriptive surplus or mismodel.

\begin{example}
Consider a representation $r$ consisting of observed credit-risk outcomes for a collection of customers. Let $d=\langle TM,a_0\rangle$ be a decodable description encoding a trained machine-learning model, where $TM$ implements the prediction procedure and $a_0$ contains the input data. Suppose that the model consists of a large ensemble of decision trees, some of which contribute little to its predictions. A reduction procedure may simplify the model by removing selected trees or other computational components. Assume that the chosen reduction operator is defined on $d$ and produces $\operatorname{red}(d)=(d_1,a)$, where $d_1$ encodes the simplified prediction procedure and $a$ encodes the removed components together with the information needed to restore the original description. By definition $\ell(d_1)\leq\ell(d)$, and the fixed reconstruction function satisfies $p(d_1,a)=d$. The reduced description may produce predictions that differ from those of the original model $\Gamma(d_1)\neq\Gamma(d)$. Nevertheless, the original description remains recoverable from the two components. Furthermore, the information required to reconstruct it from the reduced description satisfies
\[
K(d\mid d_1)=K(a\mid d_1)+O(1).
\]
If the removed components were unnecessary for describing the observed outcomes, the reduction may decrease descriptive surplus. Conversely, removing components that contain relevant information may increase descriptive deficiency. Thus, reducing the length of a computational model does not necessarily improve its descriptive quality. The effect depends on the information retained, the information discarded, and the target representation.
\end{example}

Reduction therefore provides a computational mechanism for simplifying descriptions by separating retained information from information that may be discarded. It complements augmentation, which incorporates additional information while preserving the original description. Neither operation guarantees an improvement in descriptive quality.

\section{Conditional Descriptions}
\label{sec:conditional_descriptions}


Scientific descriptions are rarely constructed in isolation. They typically rely on mathematical procedures, established models, computational tools, and other knowledge already available within a scientific community. Rather than reproducing all this information, scientists describe only what is needed beyond the existing knowledge. A \emph{conditional description} formalizes this practice by specifying a computation relative to an explicitly defined background.

Conditional descriptions extend the unconditional framework introduced earlier by allowing computations to access additional background information. This background is not included in the description itself, and its encoding cost is not charged when measuring the additional descriptive information. Nevertheless, the background must be specified to ensure that the resulting computation is well defined.

We represent background knowledge by a decodable description $c\in\mathcal{D}^\top$, whose output $b=\Gamma(c)$ is made available to the conditional computation. This output may encode numerical data, mathematical expressions, computational procedures, or other reusable resources. The background need not contain all the knowledge available within a scientific discipline, but only the information assumed available for the particular investigation.

To formalize conditional evaluation, we fix an optimal universal conditional prefix-free interpreter $U$. Its first argument is a finite computational code, and its second argument is the background string supplied as auxiliary input. For each fixed background $b$, the set $\left\{d\in\mathcal{B}^\ast:U(d,b)\downarrow\right\}$ is prefix-free. The interpreter uses fixed coding conventions that allow unconditional descriptions to be simulated with a constant description-length overhead.

\begin{definition}
\label{def:conditional_description_function}
Let $c\in\mathcal{D}^\top$ be a background description. We define the \emph{set of decodable conditional descriptions}\index{Conditional description} relative to $c$ as
\[
\mathcal{D}_c^\top = \left\{d\in\mathcal{B}^\ast:U(d,\Gamma(c))\downarrow\right\}.
\]
We define the \emph{conditional description function} \index{Conditional description function} relative to $c$ as
\[
\Gamma_c: \mathcal{D}_c^\top \longrightarrow \mathcal{B}^\ast, \qquad \Gamma_c(d)=U(d,\Gamma(c)).
\]
\end{definition}

Thus, $\Gamma_c(d)$ is the finite binary output produced by the conditional description $d$ when the information generated by $c$ is available as background. The function is total on $\mathcal{D}_c^\top$, since this set contains precisely those codes whose conditional computations terminate.

Conditional decodability must be distinguished from unconditional decodability. A code may terminate when its required background is supplied without determining a terminating computation under the unconditional execution convention. Consequently, membership in $\mathcal{D}_c^\top$ does not require membership in $\mathcal{D}^\top$. This distinction does not introduce a new fundamental computational object. The complete computation, consisting of the conditional specification together with its background, can still be realized as an ordinary decodable description.

\begin{proposition}
\label{prop:conditional_description_realization}
For every background description $c\in\mathcal{D}^\top$ and every $d\in\mathcal{D}_c^\top$, one can effectively construct an ordinary description $d^{[c]}\in\mathcal{D}^\top$ such that
\[
\Gamma(d^{[c]})=\Gamma_c(d).
\]
\end{proposition}
\begin{proof}
Using the fixed specialization convention, construct a machine $M_c$ that, on input $d$, first executes $c$ to obtain $b=\Gamma(c)$ and then simulates $U(d,b)$. Since $c\in\mathcal{D}^\top$, the first computation terminates. Since $d\in\mathcal{D}_c^\top$, the second computation also terminates. Moreover, the halting domain of $M_c$ is $\mathcal{D}_c^\top$, which is prefix-free. Thus, $M_c$ can be realized within the permitted machine convention. The ordinary description $d^{[c]}=\langle M_c,d\rangle$ therefore belongs to $\mathcal{D}^\top$ and satisfies
\[
\Gamma(d^{[c]}) = M_c(d) = U(d,\Gamma(c)) = \Gamma_c(d).
\]
\end{proof}

This proposition connects conditional descriptions with the descriptive framework already established. The conditional code $d$ specifies the additional computation, while $d^{[c]}$ provides a complete executable account that includes the means to obtain the background. The two objects should not be confused when measuring descriptive length. The length $\ell(d)$ measures the additional specification supplied when the background is available. The length $\ell(d^{[c]})$ measures the complete encoded description, including its realization of the background and the computational structure needed to combine them. Under the convention adopted here, conditional evaluation accesses a background description through its output. Consequently, if $\Gamma(c_1)=\Gamma(c_2)$, then the two backgrounds induce the same conditional domain and the same conditional description function, even though their complete computational realizations may have different lengths.

A conditional description may produce an output that differs from its intended target. Access to background knowledge does not guarantee exact reconstruction, just as unconditional decodability does not guarantee exactness. We therefore distinguish conditional descriptions generally from those that reconstruct a specified string exactly.

\begin{definition}
\label{def:conditional_description}
Let $r\in\mathcal{B}^\ast$ be a finite target string and let $c\in\mathcal{D}^\top$ be a background description. We define the \emph{set of exact conditional descriptions}\index{Exact conditional description} of $r$ given $c$, denoted by $\bar{\mathcal{D}}_{r\mid c}$, as
\[
\bar{\mathcal{D}}_{r\mid c} = \left\{d\in\mathcal{D}_c^\top:\Gamma_c(d)=r\right\}.
\]
\end{definition}

An element of $\bar{\mathcal{D}}_{r\mid c}$ reconstructs $r$ exactly when the background generated by $c$ is available. This is an exactness condition relative to the background, not a claim that the conditional code reconstructs $r$ on its own. As in the unconditional case, exactness concerns the target string rather than its adequacy as a representation of an entity. Even an exact conditional description may reproduce an incomplete or misleading representation perfectly.

Every finite target string admits an exact conditional description: a program can ignore the background and simply output the target. Thus, $\bar{\mathcal{D}}_{r\mid c}$ is nonempty. We can consequently identify those exact conditional descriptions for which no shorter alternative exists under the same background.

\begin{definition}
\label{def:minimal_conditional_description}
Let $r\in\mathcal{B}^\ast$ and $c\in\mathcal{D}^\top$. We define the \emph{set of minimal conditional descriptions} \index{Minimal conditional description} of $r$ given $c$, denoted by $\mathcal{D}_{r\mid c}^\star$, as
\[
\mathcal{D}_{r\mid c}^\star = \left\{d\in\bar{\mathcal{D}}_{r\mid c}\;\middle|\;
\nexists d'\in\bar{\mathcal{D}}_{r\mid c}: \ell(d')<\ell(d) \right\}.
\]
\end{definition}

We write $d_{r\mid c}^\star$ to denote an arbitrary element of $\mathcal{D}_{r\mid c}^\star$. This notation does not imply uniqueness.

Minimal conditional descriptions exist because the set of exact conditional-description lengths is a nonempty subset of the natural numbers. Furthermore, there are only finitely many minimal conditional descriptions of any fixed target under any fixed background, since they all have the same finite length. Using $U$ as the reference interpreter for conditional Kolmogorov complexity, we obtain
\[
\ell(d_{r\mid c}^\star) = \min \left\{\ell(d):U(d,\Gamma(c))=r \right\} = K(r\mid\Gamma(c)).
\]
Thus, minimal conditional-description length measures the least additional encoded information needed to reconstruct the target once the background has been supplied. Minimality remains relative to the chosen coding conventions and, in this case, to the specified background.

% Subsction: Additional and Total Descriptive Information

\subsection*{Additional and Total Descriptive Information}

The principal purpose of conditional descriptions is to distinguish the information contributed by a scientific account from the information it presupposes. The background may be substantial, but it is not charged again when measuring the additional description. This accounting convention does not imply that the background contains no information, required no effort to establish, or is scientifically correct. It means only that the background is treated as an available resource for the assessment under consideration.

The relationship between conditional and unconditional description lengths makes this distinction precise.

\begin{proposition}
\label{prop:description_conditional_inequality}
There exist constants $k_0,k_1$, independent of the target string and background description, such that, for every $r\in\mathcal{B}^\ast$ and $c\in\mathcal{D}^\top$, setting $b=\Gamma(c)$, we have
\[
K(r\mid b)\leq K(r)+k_0
\]
and
\[
K(r)\leq K(b)+K(r\mid b)+k_1.
\]
\end{proposition}
\begin{proof}
For the first inequality, a fixed conditional interpreter can ignore its background input and execute an unconditional description of $r$. Under the fixed universal coding conventions, this simulation requires only a constant description-length overhead. Hence
\[
K(r\mid b)\leq K(r)+k_0.
\]
For the second inequality, a program can first execute a shortest prefix-free description of $b$ and then execute a shortest conditional description of $r$ with $b$ as auxiliary input. These computations can be combined by a fixed interpreter. Prefix-freeness permits their codes to be parsed in sequence, and the interpreter contributes a fixed overhead. Therefore,
\[
K(r)\leq K(b)+K(r\mid b)+k_1.
\]
\end{proof}

The first inequality shows that supplying background information cannot increase the shortest additional description length by more than a fixed coding overhead: the computation can always ignore the background. In particular, for $r\in\mathcal{R}$, the conventions established in Section~\ref{sec:minimal_descriptions} give
\[
\ell(d_{r\mid c}^\star) \leq \ell(d_r^\star)+k_0.
\]
The second inequality shows that conditioning does not remove the need to account for information when the background is unavailable. A complete description can be obtained by supplying the background and then the additional conditional description. Equivalently, for a fixed background,
\[
K(r)-K(r\mid b)\leq K(b)+k_1.
\]
The reduction in additional descriptive information is therefore bounded by the algorithmic information available in that background, up to a fixed constant.

The possible reduction can nevertheless be substantial. If $\Gamma(c)=r$, a fixed conditional program can copy the background and output $r$, so
\[
K(r\mid\Gamma(c))=K(r\mid r)=O(1).
\]
As the complexity of the target varies, the difference between its unconditional and conditional description lengths can be arbitrarily large. This illustrates the importance of specifying what has already been supplied rather than evaluating a description in isolation.

These statements concern shortest achievable description lengths. They do not imply that an available description is minimal, that scientists can identify a minimal conditional description, or that a shorter conditional code requires less computational effort to execute.

\begin{example}
\label{ex:conditional_description_scientific_background}
Consider a scientific model specified by the differential equation
\[
\ddot{x}+\omega^2x=0.
\]
Suppose that a background description $c$ provides an interpreter for finitely encoded differential equations, rational arithmetic, a specified finite-step numerical integration procedure, and fixed input and output conventions. A conditional description $d$ supplies the model equation, a finitely encoded value of $\omega$, the initial conditions, and the finite evaluation schedule. The background procedures are available during execution and need not be reproduced within $d$. Under the stipulated terminating numerical procedure, the conditional description function produces a finite encoding of the predicted positions:
\[
\Gamma_c(d) = \left\langle\widehat{x}(t_1),\ldots,\widehat{x}(t_n) \right\rangle.
\]
Let $r$ encode observed positions at the same times, using compatible output conventions. In general $\Gamma_c(d)\neq r$, since the mathematical model and its numerical realization need not reproduce the observations exactly. The background makes the computational account executable without requiring the description to repeat the numerical infrastructure. However, the equation, parameter values, and experimental inputs remain part of the additional specification unless they have explicitly been included in the background. The complete computation can also be encoded as an ordinary description $d^{[c]}$. Evaluating its full length answers a different question from evaluating $\ell(d)$: the former concerns the complete computational account, while the latter concerns what must be supplied beyond the resources already available.
\end{example}

% Subsection: Choice and Reuse of Background Knowledge

\subsection*{Choice and Reuse of Background Knowledge}

Conditional assessment is meaningful only relative to an identified background. When comparing descriptions under a common scientific framework, that background should be fixed so that differences in descriptive cost reflect differences in the additional accounts being compared. Otherwise, information can be moved arbitrarily from a description into its background, making the description appear shorter without reducing the information required by the complete account. In the extreme case, placing the target itself in the background makes exact conditional reconstruction trivial. This is mathematically legitimate, but it answers a different question from describing the target without prior access to it.

The choice of background therefore depends on the purpose of the investigation. A mathematical procedure may be treated as established infrastructure in one comparison while its own descriptive cost is the subject of another investigation. Likewise, a previously developed model may become background for a later account that extends or applies it. Changing the background is permitted, but it changes the conditions under which descriptive economy is assessed.

Several background descriptions can be made available together. If $c_1,\ldots,c_n\in\mathcal{D}^\top$, their outputs can be collected using a fixed computable encoding:
\[
b = \left\langle\Gamma(c_1),\ldots,\Gamma(c_n)\right\rangle.
\]
Since each background description terminates, a computational procedure can execute them and produce this finite string. The resulting computation admits an ordinary decodable description, so multiple background resources can be treated through the same construction without introducing a separate conditioning operation.

Backgrounds can also be extended while retaining access to earlier resources. For example, if $b'=\langle b,z\rangle$, under a fixed computable pairing convention, then a conditional program can recover $b$ and ignore $z$. Consequently,
\[
K(r\mid b')\leq K(r\mid b)+O(1).
\]
This expresses the reuse of previously available information. It does not guarantee that a particular scientific description becomes more accurate or that its mismodel decreases.

Finally, background availability must be distinguished from background correctness. A description may execute relative to assumptions or data that are incomplete, misleading, or subsequently rejected. Conditional reconstruction establishes what can be produced given the specified resources; it does not independently justify those resources.

Conditional descriptions thus formalize how scientific accounts can be concise without being computationally incomplete. The additional description specifies what is supplied for the investigation, while the background specifies what may be reused. Their combination remains an ordinary computational description within the theory.

\section{Descriptions of Research Areas}
\label{sec:description_of_areas}

Scientific inquiry frequently concerns collections of related entities rather than individual entities considered in isolation. The representations of these entities may exhibit common regularities, allowing them to be described using shared mathematical structures. For example, a single physical law may account for observations of several systems, with differences between the systems captured by their parameters or initial conditions. This motivates the study of descriptions of research areas.

A straightforward way to describe a finite research area is to combine descriptions of its constituent representations. This construction preserves the individual computational accounts while organizing them into a single description.

Let $(r_i,d_i)\in\mathcal{H}_{e_i} i=1,\ldots,n$, be hypotheses associated with the entities in $F$. Thus, each $d_i$ is an extended description of its corresponding representation $r_i$. We may construct a decodable description $d_F$ that executes the individual descriptions and collects their outputs using the same sequence encoding employed for the area representation.

\begin{definition}
\label{def:componentwise_area_description}
Let $F=\{e_1,\ldots,e_n\}\subseteq\mathcal{A}$ be a nonempty finite subarea with a fixed ordering, and let $(r_i,d_i)\in\mathcal{H}_{e_i}$ for each $i=1,\ldots,n$. We define a \emph{componentwise description} \index{Componentwise description of a research area} of the area representation $\rho_F=\langle r_1,\ldots,r_n\rangle$ as
\[
d_F = \left\langle TM_{\mathrm{joint}}, \langle d_1,\ldots,d_n\rangle \right\rangle,
\]
where $TM_{\mathrm{joint}}$ is a fixed permitted Turing machine that executes each component description and produces the encoded sequence of their outputs:
\[
\Gamma(d_F) = \left\langle \Gamma(d_1),\ldots,\Gamma(d_n) \right\rangle.
\]
\end{definition}

Since every $d_i$ is decodable, each component computation terminates. The joint computation therefore also terminates, and $d_F\in\mathcal{D}^\top$. The fixed machine uses a prefix-free encoding of its input sequence, ensuring compatibility with the computational conventions established earlier in this chapter.

The component descriptions can be recovered effectively from $d_F$ by parsing its input. Their association with the corresponding entities is determined by the fixed ordering of $F$, without requiring additional entity identifiers. If every component description is exact, then $\Gamma(d_i)=r_i$ for all $i$, and consequently $\Gamma(d_F)=\rho_F$. Thus, $d_F$ is an exact description of the area representation. In general, however, the individual descriptions need not be exact. If one or more components produce outputs different from their intended representations, the resulting area description may also differ from $\rho_F$.

Componentwise descriptions provide a simple way to organize existing
hypotheses, but they do not necessarily exploit regularities shared by
the representations. Each component description is supplied separately,
even when several components rely on the same mathematical structures.

% Subsection: Joint Descriptions

\subsection*{Joint Descriptions}

A more general approach is to construct a single computational description of the area representation, without requiring it to be assembled from independent descriptions of the individual representations. Let $\rho_F=\langle r_1,\ldots,r_n\rangle$ be an area representation. A joint description $d_F\in\mathcal{D}^\top$ may implement a computational procedure intended to account for the entire collection. Its output can be compared with $\rho_F$, using the same encoding conventions. Such a description need not contain separately recoverable descriptions of each component. Instead, it may use common computational structures to produce their outputs. In particular, a mathematical relationship that applies to several entities may be encoded once and reused with different parameters or inputs.

The potential advantage of joint descriptions can be understood through
Kolmogorov complexity. When representations are considered independently,
their minimal descriptions must account for their information separately.
When they are considered jointly, shared algorithmic structure may reduce
the total amount of information required.

\begin{proposition}
\label{prop:area_joint_complexity}
Let $r_1,\ldots,r_n\in\mathcal{B}^\ast$, with $n\geq 1$, and let $\rho_F=\langle r_1,\ldots,r_n\rangle$ be their joint encoding. Then
\[
K(\rho_F) \leq \sum_{i=1}^{n}K(r_i)+K(n)+O(1).
\]
\end{proposition}
\begin{proof}
For each $r_i$, choose a minimal prefix-free description of length $K(r_i)$. A fixed computational procedure can decode the integer $n$, execute the $n$ descriptions in sequence, and encode their outputs using the prescribed self-delimiting representation of finite sequences. The resulting program reconstructs $\rho_F$. Its length is bounded by the sum of the individual minimal-description lengths, the length $K(n)$ needed to specify the number of components, and the constant overhead of the fixed procedure. Therefore,
\[
K(\rho_F) \leq \sum_{i=1}^{n}K(r_i)+K(n)+O(1).
\]
\end{proof}

The proposition establishes an upper bound based on describing the components independently. It does not imply that a minimal joint description must have this structure. When the representations share algorithmic information, their joint complexity may be substantially smaller. For example, if all the components are identical to a string $r$, then $\rho_F=\langle r,\ldots,r\rangle$ can be reconstructed by describing $r$ once and specifying the number of repetitions. Consequently,
\[
K(\rho_F)\leq K(r)+K(n)+O(1),
\]
rather than requiring an independent description of every occurrence
of $r$.

More generally, related representations may share mathematical relationships, computational procedures, or other regularities. A joint description can exploit these relationships by encoding the common structure once and supplying only the information specific to each component.

\begin{example}
Consider a research area consisting of several adsorption systems, each represented by experimental measurements of the amount of gas adsorbed at different equilibrium pressures. Suppose that the systems are described using the Langmuir adsorption isotherm, introduced in Section~\ref{sec:models}:
\[
q(P)=\frac{q_{\max}KP}{1+KP}.
\]
For each system $e_i$, let $r_i$ encode its experimental observations, and let
\[
\theta_i=(q_{\max,i},K_i)
\]
denote its finitely encoded model parameters. The pressure values at which predictions are required are encoded in an input $a_i$. One approach is to construct an independent description for every system, repeating the implementation of the Langmuir equation in each description. Alternatively, a joint description can encode the common mathematical structure once, together with the parameters and inputs of the individual systems. A Turing machine implementing this structure can evaluate the model for each pair $(\theta_i,a_i)$ and produce the joint output
\[
\Gamma(d_F) = \left\langle \widehat{r}_1,\ldots,\widehat{r}_n \right\rangle,
\]
where $\widehat{r}_i$ encodes the predictions for system $e_i$. The resulting description may be shorter than a collection of independent descriptions because the mathematical relationship is encoded only once. However, the predicted representations need not coincide with the experimental observations. The joint description may therefore contain descriptive deficiencies even when it achieves a substantial reduction in descriptive complexity.
\end{example}

Joint descriptive economy is particularly relevant to scientific inquiry. A general scientific law may account for observations of many different entities, replacing a collection of unrelated computational accounts with a common mathematical structure. Nevertheless, a shorter joint description does not necessarily constitute a better scientific explanation. A common model may simplify the description while failing to account for important differences between the entities. Consequently, the value of shared descriptive structures must be assessed by considering both the information captured and the information omitted.

The conditional descriptions introduced in Section~\ref{sec:conditional_descriptions} provide a complementary mechanism for reusing shared knowledge. When several descriptions rely on the same mathematical or computational background, that background can be specified once and made available to their conditional computations. Joint descriptions exploit regularities among the representations, whereas conditional descriptions distinguish additional information from knowledge already available. Both mechanisms may be used together without changing the fundamental definition of a computational description.

% Subsection: Effective Descriptions of Research Areas

\subsection*{Effective Descriptions of Research Areas}

The preceding constructions concern theoretical representations and descriptions. In practice, scientific inquiry proceeds with effective representations and the descriptions that have been considered as models of them.

Recall that Chapter 3 defines the effectively known part of a research area $\mathcal{A}$ at time $t$ as $\hat{\mathcal{A}}^{\,t} = \mathcal{A}\cap\hat{\mathcal{E}}^{\,t}$. An effectively known entity need not have an effective description. It may have entered scientific consideration through observations or other representations before any computational model has been proposed.

For a finite subset
\[
F=\{e_1,\ldots,e_n\}\subseteq\hat{\mathcal{A}}^{\,t},
\]
suppose that at least one known hypothesis is available for every entity. We may then select $(r_i,d_i)\in\hat{\mathcal{H}}_{e_i}^{\,t} i=1,\ldots,n$. The representations determine the effective area representation
\[
\hat{\rho}_F^{\,t} = \langle r_1,\ldots,r_n\rangle,
\]
while the descriptions provide computational accounts that have been considered in scientific practice.

As in the theoretical case, the selected component descriptions can be
combined into a decodable description
\[
d_F=
\left\langle
TM_{\mathrm{joint}},
\langle d_1,\ldots,d_n\rangle
\right\rangle,
\]
satisfying
\[
\Gamma(d_F)
=
\langle\Gamma(d_1),\ldots,\Gamma(d_n)\rangle.
\]
This construction does not require the component descriptions to be extended descriptions of their intended representations. A known hypothesis may contain an inaccurate, incomplete, or entirely uninformative description.

The construction also does not imply that the resulting joint description has itself been proposed or investigated within scientific practice. It establishes only that a computational description of the selected collection can be constructed from the available components. A joint model independently considered by scientists may instead have a different computational structure, including shared mathematical relationships that are not explicitly represented in the individual descriptions.

The distinction between theoretical and effective descriptions is therefore preserved at the level of research areas. The former characterize computational possibilities, while the latter concern descriptions that have actually entered scientific investigation.

Since effective representations, effective descriptions, and known hypotheses are defined cumulatively, the historical collection of entities for which at least one known hypothesis exists cannot decrease over time for a fixed research area. However, this does not imply that scientific understanding improves monotonically. Newly proposed descriptions may be inaccurate or unnecessarily complex, and earlier descriptions may subsequently be rejected. An increase in descriptive coverage must therefore be distinguished from a reduction in nescience.

% Subsection: Descriptive Quality of Research Areas 

\subsection*{Descriptive Quality of Research Areas}

Describing a research area raises a question that does not arise when considering entities independently: whether the quality of the joint description should be evaluated as a whole or through the quality of its individual components.

A componentwise assessment examines the relationships between each representation $r_i$ and its corresponding description $d_i$. This approach makes it possible to reuse the existing measures of descriptive deficiency, surplus, and mismodel. A joint assessment instead considers a description $d_F$ relative to the complete area representation $\rho_F$. Such an assessment may capture regularities shared by the different components that are not visible when they are evaluated independently. These approaches need not produce equivalent results. In particular, the joint area representation is not necessarily an element of the theoretical representation space $\mathcal{R}$, so the existing definition of mismodel cannot automatically be applied to it without specifying an appropriate extension or evaluation convention. We therefore leave the evaluation of descriptive quality to the subsequent chapters on mismodel and nescience. At this stage, the important distinction is between collecting existing descriptions and constructing a computational account that exploits common regularities across multiple representations.

Descriptions of research areas thus extend the descriptive framework from individual entities to collections of related entities. Their principal significance is not merely that several descriptions can be combined into one binary string, but that a single computational structure may account for information distributed across many representations. This provides a formal foundation for studying scientific laws and models whose explanatory scope extends beyond individual phenomena.
















\section{Old Descriptions of Research Areas}
\label{sec:description_of_areas}

Research areas are subsets of the set of entities \(\mathcal{E}\). Once individual
entities admit descriptions, it is natural to ask how an entire research area can be
described. Intuitively, a description of an area should collect descriptions of the
entities that compose it in such a way that each component can be identified and,
when needed, recovered effectively. In this way, a research area is not treated as an
undifferentiated aggregate, but as a structured family of entity-level descriptions.

As in the case of representations, two difficulties appear immediately. First, a research
area need not be finite, whereas every description is a finite binary string. Second,
some entities in the area may fail to admit any exact description, or may only be
associated in practice with effective descriptions. For this reason, the description of a
research area must be understood relative to finite subsets of the area and, in practice,
relative to the effective descriptions currently available.

Recall that, for each entity \(e \in \mathcal{E}\), the set \(\mathcal{D}_e\) denotes the set of
valid descriptions associated with \(e\), and \(\hat{\mathcal{D}}_e\) denotes the set of effective
descriptions of \(e\).

\begin{definition}
Let \(\mathcal{A} \subseteq \mathcal{E}\) be a research area. We define the
\emph{describable part}\index{Describable part of a research area} of \(\mathcal{A}\) as
\[
\mathcal{A}^{\mathcal{D}}
=
\{e \in \mathcal{A} : \mathcal{D}_e \neq \varnothing\}.
\]
\end{definition}

Thus, \(\mathcal{A}^{\mathcal{D}}\) consists of those entities in the area for which at least
one valid description exists. If \(\mathcal{A}\) contains entities outside
\(\mathcal{A}^{\mathcal{D}}\), then no exact area description can include them as individually
described components.

To describe several entities together, we must separate their descriptions and attach
identifiers that allow each component to be recognized. Any standard self-delimiting
encoding of finite strings may be used for this purpose.

\begin{definition}
Let \(\mathcal{A} \subseteq \mathcal{E}\) be a research area, let
\[
F=\{e_1,\ldots,e_n\}\subseteq \mathcal{A}
\]
be a finite subset, and let \(d_i \in \mathcal{D}_{e_i}\) for each \(i=1,\ldots,n\). Let
\(\iota_1,\ldots,\iota_n \in \mathcal{B}^\ast\) be pairwise distinct identifier strings. We define a
\emph{description of the finite subarea \(F\)}\index{Description of a finite subarea} as any
finite binary string of the form
\[
\Delta_F
=
\langle (\iota_1,d_1),\ldots,(\iota_n,d_n)\rangle,
\]
where \(\langle \cdot,\cdot\rangle\) and its finite iteration denote a fixed self-delimiting
computable encoding of pairs and finite sequences of binary strings.
\end{definition}

The identifiers \(\iota_i\) need not carry scientific meaning by themselves. Their role is
only to make it possible to separate the different components of the area description
and determine which description is associated with which entity in the represented
finite family.

\begin{definition}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a research area. We say that a binary string
\(\Delta\in\mathcal{B}^\ast\) is an \emph{extended description of the area}
\index{Extended description of a research area} if there exists a finite subset
\[
F=\{e_1,\ldots,e_n\}\subseteq \mathcal{A}
\]
and strings \(d_i\in \mathcal{D}_{e_i}\) such that
\[
\Delta = \langle (\iota_1,d_1),\ldots,(\iota_n,d_n)\rangle
\]
for some pairwise distinct identifiers \(\iota_1,\ldots,\iota_n\).
\end{definition}

This definition deliberately allows area descriptions to be partial. The string
\(\Delta\) need not describe all entities in \(\mathcal{A}\), but only a finite subset of them.
This is unavoidable whenever \(\mathcal{A}\) is infinite, and it remains useful even when
\(\mathcal{A}\) is finite but some of its entities are not describable.

\begin{definition}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a research area. We say that \(\Delta\) is a
\emph{complete area description}\index{Complete area description} of \(\mathcal{A}\) if
\(\Delta\) is an area description associated with the finite set
\[
F=\mathcal{A}^{\mathcal{D}}.
\]
In particular, such a complete description can exist only if \(\mathcal{A}^{\mathcal{D}}\) is finite.
\end{definition}

Thus, if \(\mathcal{A}\) is finite and all its entities admit at least one description, then
\(\mathcal{A}\) admits a complete area description. If \(\mathcal{A}\) contains entities with no
description, then at best one can describe its describable part
\(\mathcal{A}^{\mathcal{D}}\).

The next proposition formalizes the main purpose of tagging individual descriptions:
the description of an area preserves the identity of its components.

\begin{proposition}
\label{prop:recover_components_area_description}
Let
\[
\Delta_F=\langle (\iota_1,d_1),\ldots,(\iota_n,d_n)\rangle
\]
be a description of a finite subarea \(F=\{e_1,\ldots,e_n\}\subseteq \mathcal{A}\). Then
each pair \((\iota_i,d_i)\) can be recovered effectively from \(\Delta_F\).
\end{proposition}

\begin{proof}
By construction, \(\Delta_F\) is encoded using a fixed self-delimiting computable coding
of finite sequences of pairs. Therefore, there exists a computable decoding procedure
that parses \(\Delta_F\) and returns each pair \((\iota_i,d_i)\). Hence every component
description is effectively recoverable from the area description.
\end{proof}

The previous proposition shows that a description of a research area does not erase the
individual descriptions of its members, but rather organizes them within a single
computable object.

Area descriptions are generally not unique.

\begin{proposition}
\label{prop:area_descriptions_not_unique}
Descriptions of research areas are not unique.
\end{proposition}

\begin{proof}
Non-uniqueness may arise in at least two ways. First, an entity
\(e\in\mathcal{E}\) may admit several distinct descriptions \(d,d' \in \mathcal{D}_e\).
Second, even for a fixed family of entity-level descriptions, one may choose different
identifiers or a different order of concatenation. Therefore, the same research area may
admit multiple distinct area descriptions.
\end{proof}

This non-uniqueness is not a defect. It reflects the fact that a research area may be
organized in different descriptive styles, just as an individual entity may admit several
valid descriptions.

Finite area descriptions are also stable under finite aggregation.

\begin{proposition}
\label{prop:union_finite_area_descriptions}
Let \(F_1,F_2\subseteq \mathcal{A}\) be finite subareas with \(F_1\cap F_2=\varnothing\).
If \(\Delta_{F_1}\) and \(\Delta_{F_2}\) are descriptions of \(F_1\) and \(F_2\), respectively,
then there exists a description of \(F_1\cup F_2\).
\end{proposition}

\begin{proof}
Write
\[
\Delta_{F_1}
=
\langle (\iota_1,d_1),\ldots,(\iota_m,d_m)\rangle
\]
and
\[
\Delta_{F_2}
=
\langle (\kappa_1,d'_1),\ldots,(\kappa_\ell,d'_\ell)\rangle.
\]
Choosing the identifiers so that all
\(\iota_1,\ldots,\iota_m,\kappa_1,\ldots,\kappa_\ell\) are pairwise distinct, the string
\[
\langle
(\iota_1,d_1),\ldots,(\iota_m,d_m),
(\kappa_1,d'_1),\ldots,(\kappa_\ell,d'_\ell)
\rangle
\]
is a description of the finite subarea \(F_1\cup F_2\).
\end{proof}

This result shows that finite area descriptions are closed under finite aggregation. In
this sense, describing an area amounts to collecting identifiable entity-level
descriptions into a single structured string.

It is often useful to isolate the family of all area descriptions associated with a given
research area.

\begin{definition}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a research area. We define the set of
\emph{descriptions of the area \(\mathcal{A}\)}\index{Set of descriptions of a research area}
by
\[
\mathcal{D}_{\mathcal{A}}
=
\left\{
\Delta \in \mathcal{B}^\ast :
\Delta \text{ is an extended description of } \mathcal{A}
\right\}.
\]
\end{definition}

By definition, \(\mathcal{D}_{\mathcal{A}}\) contains all finite strings that describe finite
subsets of \(\mathcal{A}\) by means of identifiable valid descriptions of their entities.

The description of an area can also be understood as the union, in a structural sense,
of the descriptions of its finite subareas.

\begin{proposition}
\label{prop:area_description_from_finite_subareas}
Let \(\mathcal{A}\subseteq\mathcal{E}\) be a research area. Then every element of
\(\mathcal{D}_{\mathcal{A}}\) is a description of some finite subarea \(F\subseteq \mathcal{A}\).
\end{proposition}

\begin{proof}
This follows immediately from the definition of extended description of a research
area, which requires the existence of a finite subset
\(F=\{e_1,\ldots,e_n\}\subseteq \mathcal{A}\) and corresponding descriptions
\(d_i\in\mathcal{D}_{e_i}\) such that
\[
\Delta=\langle (\iota_1,d_1),\ldots,(\iota_n,d_n)\rangle.
\]
Therefore every \(\Delta\in\mathcal{D}_{\mathcal{A}}\) is associated with some finite
subarea \(F\subseteq \mathcal{A}\).
\end{proof}

In practice, however, science does not work with the full sets \(\mathcal{D}_e\) of valid
descriptions of entities, but with the effective descriptions currently available.

\begin{definition}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a research area and let \(t\) denote a time index.
We define the \emph{effectively describable part of the area at time \(t\)}
\index{Effectively describable part of a research area} by
\[
\hat{\mathcal{A}}^{\,t}_{\mathcal{D}}
=
\{e\in \mathcal{A} : \hat{\mathcal{D}}_e^{\,t}\neq \varnothing\}.
\]
\end{definition}

The set \(\hat{\mathcal{A}}^{\,t}_{\mathcal{D}}\) contains those entities of the area for which
at least one effective description is available at time \(t\).

\begin{definition}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a research area and let
\[
F=\{e_1,\ldots,e_n\}\subseteq \hat{\mathcal{A}}^{\,t}_{\mathcal{D}}
\]
be a finite subset of effectively describable entities at time \(t\). For each
\(i=1,\ldots,n\), let \(\hat{d}_i\in \hat{\mathcal{D}}_{e_i}^{\,t}\), and let
\(\iota_1,\ldots,\iota_n\in\mathcal{B}^\ast\) be pairwise distinct identifiers. We define an
\emph{effective description of the finite known subarea \(F\) at time \(t\)}
\index{Effective description of a finite subarea} as any binary string of the form
\[
\hat{\Delta}^{\,t}_F
=
\langle (\iota_1,\hat{d}_1),\ldots,(\iota_n,\hat{d}_n)\rangle.
\]
\end{definition}

Effective area descriptions are the practical counterparts of exact area descriptions.
They need not be correct or minimal, because their components are only effective
descriptions of the individual entities. Nevertheless, they encode the current
descriptive state of the part of the area that is effectively described.

\begin{proposition}
\label{prop:effective_describable_area_monotone}
Let \(\mathcal{A}\subseteq \mathcal{E}\) be a fixed research area. If \(t_1<t_2\), then
\[
\hat{\mathcal{A}}^{\,t_1}_{\mathcal{D}}
\subseteq
\hat{\mathcal{A}}^{\,t_2}_{\mathcal{D}}.
\]
\end{proposition}

\begin{proof}
If \(e\in \hat{\mathcal{A}}^{\,t_1}_{\mathcal{D}}\), then \(e\in\mathcal{A}\) and
\(\hat{\mathcal{D}}_e^{\,t_1}\neq\varnothing\). Since effective descriptions are monotonic over
time, we have \(\hat{\mathcal{D}}_e^{\,t_2}\neq\varnothing\) for all \(t_2>t_1\). Therefore
\(e\in \hat{\mathcal{A}}^{\,t_2}_{\mathcal{D}}\).
\end{proof}

As a consequence, effective descriptions of areas may be progressively extended over
time by incorporating descriptions of entities that were previously not effectively
described.

\begin{proposition}
\label{prop:effective_area_description_extension}
Let \(\mathcal{A}\subseteq\mathcal{E}\) be a fixed research area, and let
\(\hat{\Delta}_{F_1}^{\,t_1}\) be an effective description of a finite subarea
\(F_1\subseteq \hat{\mathcal{A}}^{\,t_1}_{\mathcal{D}}\). If \(t_1<t_2\), then there exists a
finite set \(F_2\) such that
\[
F_1 \subseteq F_2 \subseteq \hat{\mathcal{A}}^{\,t_2}_{\mathcal{D}}
\]
and an effective description \(\hat{\Delta}_{F_2}^{\,t_2}\) extending
\(\hat{\Delta}_{F_1}^{\,t_1}\).
\end{proposition}

\begin{proof}
By Proposition \ref{prop:effective_describable_area_monotone},
\[
\hat{\mathcal{A}}^{\,t_1}_{\mathcal{D}}
\subseteq
\hat{\mathcal{A}}^{\,t_2}_{\mathcal{D}}.
\]
Hence every entity in \(F_1\) remains effectively describable at time \(t_2\). Let
\(F_2\) be any finite subset of \(\hat{\mathcal{A}}^{\,t_2}_{\mathcal{D}}\) containing \(F_1\).
Retaining the previous effective descriptions for the entities in \(F_1\), and choosing
effective descriptions at time \(t_2\) for the entities in \(F_2\setminus F_1\), we obtain
an effective description \(\hat{\Delta}_{F_2}^{\,t_2}\) of \(F_2\) that extends
\(\hat{\Delta}_{F_1}^{\,t_1}\).
\end{proof}

This monotonicity property reflects a natural feature of scientific practice: as more
entities in an area become describable, the descriptive coverage of the area expands.

Finally, it is important to note that the description of a research area is not, in general,
a minimal description of a single entity. It is a structured object that organizes
descriptions of several entities simultaneously. For this reason, area descriptions are
best understood as a bookkeeping and modeling device that allows the theory of
nescience to be lifted from individual entities to families of related entities.

In later chapters, this lifting will make it possible to define area-level notions of
mismodel, inaccuracy, surfeit, and nescience. At that point, the description of a
research area will no longer be merely a collection of component descriptions, but the
basis for measuring how well an entire domain of inquiry is currently understood.
